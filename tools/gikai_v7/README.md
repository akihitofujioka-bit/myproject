# 議会だより編集 V7

異動してきたばかりの職員でも、画面の案内に沿って原稿入力から Word 出力まで進められるツールです。原稿を部品に分けたり、紙面上で手動移動したりする必要はありません。

## 起動

Windows で `起動.bat` をダブルクリックします。Python 3.9 と tkinter が必要です。インターネット接続、追加ソフト、pip は使いません。

最初の画面で次のどちらかを選びます。

- `新しい号を作る`: 保存先となる号フォルダを選びます。
- `続きを開く`: `号情報.json` と `紙面.json` がある号フォルダを選びます。

ツールを閉じるときは入力中の内容を保存し、次に起動すると**閉じたときの号と手順から**始まります（覚えるのは号フォルダの場所と手順の番号だけで、ツールのフォルダの `前回の続き.json` に入ります）。号フォルダを動かした・消したときは、最初の画面から「続きを開く」で選び直してください。

入力は号フォルダの `項目.json` に保存されます。保存前の内容は `項目_前回.json` に残ります。写真は `写真`、自動作成した印付き原稿は `事務局原稿`、Word は `出力/出力_…` に入ります。以前の原稿や出力は消しません。

## 15の手順

1. はじめに: 新しい号を作るか、続きを開きます。
2. 号の情報: 号数を入れ、発行年と発行月をプルダウンで選びます。発行日（月の末日）と定例会名は自動で入ります。
3. 議員名簿: 1行に1人を入力し、議長名を指定します。
4. 表紙: 写真説明と特集の題名を入れます。
5. 行政報告: 報告事項ごとに見出しと本文を入れます。
6. 当初予算または決算: 概要と質疑を入れます。
7. 議案と賛否(エクセル): 名簿からひな形を作り、Excelで入力して取り込みます。
8. 審議したこと: 会期の始まりと終わりの年月日をプルダウンで選び(紙面には「Ｒ８．９．４～９．１１」の形で入ります)、自動集計された種類と件数を確認します。違うときは表で直せます(直した件数は、エクセルを取り込み直しても変わりません。戻すときは「エクセルから数え直す」)。説明・質疑の議案名はExcelの件名から選べます。
9. 委員会報告: 委員会名、見出し(任意)、本文を入れます。ページの大見出しは「閉会中の委員会活動報告」に決まっています。
10. 一般質問: Word・メール本文・手書きの原稿を受け付け、議員ごとに題と最大4件の質問を入れます。1人1ページです。最初のページの頭には、大見出し「一般質問に◯氏が立つ」(◯は質問者の数)が自動で入ります。その左に1人目の顔写真枠と議員名、さらにその左に1人目の題が入ります。議員ごとに、1番目の質問は「大まかな質問(青字)とそれへの答」を大見出しの囲みにし(1人目は横書き、2人目は縦書き、3人目は横書き…と交互)、顔写真枠、詳しい問と答が続きます。2番目からの質問は、同じ形の中見出しのあとに詳しい問と答が続きます。紙面では、問は「質問　(質問の本文)」、答は「答弁　(答弁者)」のあと行を変えて答弁の本文(明朝)の形で入ります。確認用の Word も同じ形です。「＋追加」「編集」の窓では、質問ごと(1〜4番目のつまみ)に 見出し・見出しの答・問・答・答弁者 の欄へ入れるだけで済みます(印を打たなくてよい)。答弁者は 村長・副村長・教育長 と、その号でもう入れた役職から選ぶか、書き込みます。1つの質問の中で再質問・再答弁をするときは、その質問のつまみの「やりとりを足す」で、やりとり2、やりとり3…を足します(紙面では同じ見出しの下に、質問・答弁が続けて入ります)。まとめて貼るときは、【見出し】を付けずに問・答を続けて書くと、前の質問の続きのやりとりになります。Word・メール本文・まとめて貼る原稿は、「質問　…」「答弁　村長」(紙面と同じ書き方)、「問　…」「答　…」、「【質問】」「Ｑ．」「Ａ．」、「答弁（教育長）」、「再質問」「再答弁」も質問・答弁として読みます。答弁のあとの短い行(句点で終わらない30字まで)で、次の行が質問なら、次の質問の見出しにします。印がなくても、質問の行のすぐ前にある、質問・答弁の印のない1〜2行のかたまりは、1行目を見出し、2行目を見出しの答として読みます(答弁のすぐあとに空き行なしで続くときは、句点で終わらない30字までの、頭を下げていない行だけ)。議員の原稿に「（見出し）」「（見出しの答）」の印を書き足してもらえば、見出しと見出しの答も振り分けます(印のあとに続けて書いても、印だけの行の次の行に書いても読みます。【見出し】【見出しの答】でも同じ)。取り込む前の確認の窓に、質問ごとの分け方(見出し・質問・答弁者・答弁)が出るので、原稿と見比べてください。「まとめて貼る」で原稿をまとめて貼るときの書き方は `【見出し】大まかな質問` `【見出しの答】それへの答` `問　…` `答　…` `答弁者　…` の順です。
11. 特集: 特集ごとに題と本文を入れます。特集はいくつでも足せて、上から順に特集のページへ続けて入ります(それぞれ大見出しから始まります)。Word・エクセルで作った表は「Word の表を読み込む」「エクセルの表を読み込む」で取り込み(エクセルはドロップでも可)、本文の入れたい所に行の頭から `【表】表の名前` と書くと、その所にページの幅いっぱいの横書きの表が入ります。表の中身は、表の一覧の「編集」で直せます(1行が表の1行、列はタブか｜で区切ります。エクセルや Word の表をコピーして貼っても入ります)。Word から読み込んだ表は、セルの色・つないだセル・罫線・字の色や大きさを、そのまま紙面に入れます(幅は紙面に入るよう縮めます)。ただし一覧の「編集」で中身を直すと、こちらで作る細い罫線・ゴシックの表になります。エクセルから読み込んだ表と、貼り付けて作った表も、細い罫線・ゴシックの表です。大見出しなどで段の一部がふさがっていても、ページの幅の6割以上空いていれば、その幅に縮めて置きます。
12. 最終ページ: 編集後記、自由欄、次回定例会などを入れます。
13. 写真: 誰の・どの記事かを付けてJPEGまたはPNGを追加し、紙面見本をクリックして置きます。
14. 全ページの確認: 未入力、あふれ、余りを確認します。
15. Word出力: 確認用Word、確認リスト、写真配置一覧を出力します。

`次へ`で自動保存します。必須欄が空でも、理由を確認して `空のまま進む` を選べます。左の手順名を押すといつでも戻れます。完了した手順には ✓ が付きます。

## 入力のこつ

- 記入欄は TAB で次の欄、Shift+TAB で前の欄へ移れます(本文のような複数行の欄でも同じです)。
- マウスのホイール(トラックパッド)は、画面のどこで回しても、その場所をスクロールします。
- 「紙面を見る」の縦中横の数字(２桁・３桁)は、Word と同じく本文とほぼ同じ高さで描きます。画面の字の形は Word と少し違うので、最後は Word で確かめてください。
- ボタンにマウスを合わせると、そのボタンの働きが小さな窓で出ます。
- 大見出しの字は、横書きは左づめ、縦書きは上づめで入ります(行のかたまりは枠の真ん中。字が枠の線に付かないよう内側に少し余白を取ります)。
- 「紙面を見る」で大見出しをクリックして選ぶと、「枠を広く」「枠を狭く」(1行ずつ)「枠を高く」「枠を低く」(1段ずつ)で枠の大きさを変えられます。字は枠に合わせて折り返します。「元の大きさに戻す」で元に戻ります。写真や一般質問の顔写真の枠をクリックして選んだときは、「枠を広く」「枠を狭く」で写真の大きさを1つずつ変えます(顔写真は縦長のまま 顔小・顔・顔大・顔特大 の4つ。顔特大は2段)。大見出し・写真・顔写真の枠(議員名ごと)はドラッグで動かすこともできます。動かせる部品の上ではマウスの形が変わり、ドラッグ中は離すと入る場所を赤い点線の枠で見せます(つかんだ所を保ったまま動きます)。変えた大きさと位置は保存し直しても残ります。
- 「紙面を見る」の上の「置く写真」で写真を選んでから紙面をクリックすると、どの手順からでも写真を置けます。置いた写真はドラッグで動かせます。
- 最終ページの自由欄には、字のかわりに画像(写真や、Word の四角い図形を右クリック→「図として保存」で PNG にしたもの)をそのまま置けます。「自由欄の画像」の「画像を足す」(ドロップでも可)で入れると、2〜4段目に縦横の割合を保って入るだけ大きく置き、何枚かあれば上から順に並べます。画像を入れたときは、自由欄の字は紙面に出ません。
- 最終ページの意見・提言は、ふだんは決まった文が入ります。変える時だけ欄に書きます(空のままなら決まった文)。
- 「紙面を見る」は、一般質問の手順なら一覧で選んでいる(足したばかりの)議員のページから開きます。紙面を見るの窓を開いたまま元の画面で直したときは、紙面を見るの窓をクリックすると最新の内容で描き直します。画面の字は Word と形が少し違うため、枠に入りきらないときは画面だけ字を詰めて描きます。
- 「紙面を見る」は、今編集している手順の項目のページから開きます(一般質問を編集中なら一般質問のページ、議案と賛否なら賛否表のページ)。同じ手順でもう一度開くと、前に見ていたページから出ます。
- 「紙面を見る」は、最初は窓の幅いっぱいに大きく描きます。上下はホイールで動かします。「拡大」「縮小」、ページ全体を見る「全体」、元に戻す「幅に合わせる」のボタンがあります(Ctrl を押しながらホイールでも拡大・縮小)。ページは「◀ 前のページ」「次のページ ▶」のボタンか、キーボードの ← → で送ります。ホイールでページの下の端までスクロールし、さらに回すと次のページへ、上の端でさらに上へ回すと前のページへ送ります。
- Windows では、ファイルをエクスプローラーから画面へドロップして読み込めます。手順ごとに落とせるものが決まっています。
  - Word(.docx・.doc): 行政報告・委員会報告・一般質問・特集
  - エクセル(.xlsx): 議案と賛否・特集(表)
  - エクセル(.xlsx): 議案と賛否
  - 写真(JPEG・PNG): 写真
  - メールの添付は、いったんデスクトップなどに保存してからドロップしてください(メールソフトから直接は落とせません)。
- 行政報告・委員会報告・特集の Word は、見出しごとに分けて、今の内容の後ろに足します。入れる前に確認の窓で中身を見比べてください。Word の中の写真は号の「写真」フォルダへ写すだけで、紙面には「写真」の手順で置きます。

- 一覧は `＋追加`、`削除`、`上へ`、`下へ` で整えます。
- 予算・決算の `まとめて貼る` では、`問　` と `答　` で始まる行を自動で分けます。分けられない文章も概要として残ります。
- 行政報告、委員会報告、特集は、入り切らない文章を同じ区分の次ページへ自動で送ります。
- `紙面を見る` で色分けした配置と、あふれ行数・削る字数の目安を確認できます。
- 1人目の題(横書き)が長いときは、顔写真枠の入る幅を残して題の枠の中で折り返します。決まった所に入らないときも、顔写真枠と議員名は近くの空いた所に入れます(消えません)。
- 一般質問の顔写真枠の下には、議員名(例「見本 太郎議員」)が入ります。枠の位置は、紙面を見るで枠をドラッグすると議員名ごと動かせ、入力を直して保存し直しても残ります。
- 一般質問の顔写真枠は自動です。実写真を入れる場合は写真手順からページを指定します。

## 当初予算のページ(4・5月号)

4・5月号は「予算・決算」の手順で、第202号と同じ見開き2ページの当初予算を作ります(ページ割りでも2ページ取ります)。

- 1ページ目: 題の囲み(例「令和８年度当初予算」。発行年から自動)、円グラフの題、円グラフの指示(楕円。印刷所への指示)と歳出総額、円グラフの横に入れる主な事業(費目・事業名・説明)、各会計予算(公営企業会計・特別会計の金額)
- 2ページ目: 大見出し(例「日高村７２億円でスタート」)、注目する事業(事業名・金額・説明)、前の年度の事業の欄
- 円グラフそのものは作りません。印刷所が広報などのものを使う前提で、指示と数字を入れます

## 決算のページ(10月号)

10月号は「予算・決算」の手順で、第204号と同じ形の決算のページを作ります。

- 題(例「令和７年度決算認定」。発行年から自動。10月号は前の年度)と、右に並ぶ会計の種類
- 写真(決算審査の様子など)。写真フォルダに入れてから選びます
- 円グラフの指示(楕円の囲み。印刷所への指示です)
- 会計別決算額: 1行に1つの会計を入れます。「まとめ」が同じ行はつながります(「特別会計」は縦書き、「簡易水道事業会計」のような長いものは横書きで2行に分けます)
- 決算の質疑: 会計名(【一般会計】など)・問・答。下の段に縦書きで入ります。あふれたら行数が出ます

## 委員会報告のページ

「委員長名」を入れると(委員長報告)、その報告の見出しのすぐあと(本文の前)に委員長の顔写真の枠と、その下に「◯◯委員長」の名前が入ります。紙面を見るでドラッグして置き場所を決め、「枠を広く」「枠を狭く」で大きさを変えられます。

まとまりの小見出しに課長名など(「総務課長」のように「長」などで終わる短い名前)を入れると、見出しにせず1行の名前として入れ、次の行から説明を始めます。委員会名が1行に入らないときは、1行目を上づめ、2行目を下づめにします。

「＋追加」「編集」の窓では、委員会名・記事の見出しと、小見出しごとのまとまり(まとまり1〜6のつまみ)に分けて入れます。小見出しの行に【見出し】の印を打たなくて済みます。

ページの大見出しは **「閉会中の委員会活動報告」に決まっています**(入力は要りません)。その下に報告ごとに、**委員会名**、**記事の見出し**(任意)、本文の順で入ります。本文の途中の小見出し(「調査日」「所感」など)は、行の頭に `【見出し】` を付けます。

## 議案と賛否のExcel

1. 議員名簿を保存してから、`ひな形を作る`で `.xlsx` の保存先を選びます。同名があっても `_2` のような別名になり、上書きしません。
2. Excelの「議案と賛否」シートで、1行に1件ずつ区分・議案番号・件名・議決結果を入力し、議員列へ `○`（賛成）、`●`（反対）、`欠席`、`議長`を入れます。詳しい書き方は「書き方」シートにあります。
3. `エクセルを取り込む`で保存したファイルを選びます。件数は審議したことへ自動反映され、結果と注意が画面に出ます。元ファイルは変更せず、号フォルダの `賛否` に時刻付きの複製を残します。

前から使っている賛否のエクセル(.xlsx)も、そのまま取り込めます。

- 見出しの行は上から15行の中で探します(1行目に表の題があってもかまいません)
- 見出しが2〜3段に分かれていても(上の段に区分・件名・議決結果、下の段に議員名 など)読みます。件名の見出しが見つからないときは、いちばん長い文が入る列を件名とみなし、そう読んだことを注意に出します
- 見出しは「議案・発議案」「議案名」→件名、「結果」→議決結果、「種類」→区分 のような言い方でも読みます
- 議員名は空白や改行を無視して名簿と照らし合わせます(「見本　太郎」と「見本 太郎」は同じ)
- 印の「〇」(漢数字のゼロ)・「◯」は「○」、「賛成」は「○」、「反対」は「●」として読みます
- 区分のセルが縦につながっている(結合)ときは、上の行の区分を引き継ぎます
- エクセルのふりがなは読みません
- 議長が議員名簿の一覧に無く「議長名」の欄だけにあっても、議長の列として読みます。見出しが「議長」だけの列や、「議長　○○」「○○議員」のように名前の前後に言葉が付いた見出しも読みます

それでも「名簿にある議員の列がありません」と出るときは、名簿の名前とエクセルの見出しの名前の字が違っていないか(旧字・別の字など)を見てください。

取り込んだあとの確認の表で議案の行をダブルクリックすると、区分・件名(改行も入れられます)・議決結果を直せます。直した分は記録しておき、エクセルを取り込み直しても同じ件名の行に当て直します。

「紙面を見る」で文字をダブルクリックすると、そのページの入力欄の手順へ移ります(賛否表の見出しなら「議案と賛否」の手順)。賛否表の議案の行をダブルクリックすると、その議案の区分・件名・議決結果を直す窓が開きます。審議のページの「◎件名」の行をダブルクリックすると、その案件の件名を直す窓が開きます(賛否表に同じ件名があれば、いっしょに直せます)。説明・質疑・問・答の所をダブルクリックすると、その案件の説明と質疑を直す窓が開きます(押した問の行から書き直せます)。審議の本文の長い問・答は、段の終わりで次の段へ続きます。入りきらない分は紙面に出さず、行数を「入りません」と知らせます。直すと紙面がすぐ描き直されます。

画面では○・●を直せません。元データをExcel一つにして、Excelと画面の内容が食い違うのを防ぐためです。直す場合はExcelを直して、もう一度取り込みます。古い `.xls` や `.csv` は、Excelの「名前を付けて保存」でExcelブック `.xlsx` にしてから使います。

## Word・メール・手書きの原稿

- Word: `Word から読み込む`で `.docx` または `.doc` を選びます。問・答の分割結果を原稿と見比べ、`これで入れる`を押します。元ファイルは変更せず、`受け取った原稿`へ複製します。
- メール: 本文を貼り、引用・署名・ヘッダの「外す候補」から外す行だけを選びます。整えた本文と問・答を確認してから取り込みます。貼った元本文も `受け取った原稿`へ保存します。
- 一般質問の手順の「原稿のひな形を作る」で、議員に配る原稿のひな形(書き方の説明と、（見出し）（見出しの答）質問・答弁の見本を4つぶん)を Word で作れます。議員がこのひな形に書いた原稿は、そのまま読み込むと振り分けられます。
- 一般質問の Word 原稿は、質問者の一覧の白い所(画面のどこでも)へドロップしても読み込めます。一覧で議員を選んでから落とすと、議員を選ぶ窓でその議員が最初から選ばれています。
- 議員名は、議員名簿のプルダウンから選びます(まとめて貼る・メール本文を貼る・Word から読み込む・写真を追加)。
- 手書き: 紙を見ながら入力欄へ直接打ちます。入力後は `確認用に印刷`で横書きの普通のWordを作ります。作った Word は自動で開くので、そのまま印刷して議員に赤ペンで確認してもらいます。

受付状況は名簿の全員について、未着・入力中・議員確認待ち・確認済みで表示されます。

## 写真

メール添付は一度ファイルとして保存します。紙の写真は複合機で350dpi以上、JPEGでスキャンして追加し、紙は議員へ返します。HEICなどを読めない場合は、写真アプリでJPEGに書き出します。

写真を選び、特大(幅110mm)・大・中・小・顔と説明を指定して紙面見本の置きたい所をクリックします。置いた写真はドラッグできます。見出し・ページ外・別の写真に重なる場合は近い空きへ寄せ、本文は写真をよけて流れ直します。あふれたときは、写真を小さくする、次ページへ送る、本文を削る、のいずれかで直します。一般質問の顔写真は従来どおり印刷所用の自動枠です。

## 字が欠けないかの確かめ(初めて使うパソコンで一度)

`確かめ用の見本を作る.bat` をダブルクリックすると、架空の第998号を作ってフォルダを開きます。`出力` の中の `第998号.docx` を Word で開き、次を見てください。

- 行の端や段の下の字が切れていないか
- 写真のまわりの字が写真に重なっていないか
- 見出しの字が枠からはみ出していないか

欠けていたら、どのページのどの辺りかを担当者(ツールを直す人)に伝えてください。

## 困ったとき

- `合計…ページ` または `奇数` と出る: 一般質問の人数か委員会報告の件数を確認してください。合計は22ページ以内の偶数です。
- `あふれ` と出る: 表示された字数を目安に文章を短くするか、写真を別ページにします。
- 写真を読めない: JPEGまたはPNGへ変換します。
- 原稿の場所や内容が分からない: 前の担当者か局長に確かめます。
- 出力をやり直したい: もう一度出力します。別の `出力_…` フォルダに作られ、前の出力は残ります。

開発時の確認は `python3 -m unittest discover -s tests`、架空の見本出力は `python3 demo_edition.py` です。
