# 議会だより編集 V7

異動してきたばかりの職員でも、画面の案内に沿って原稿入力から Word 出力まで進められるツールです。原稿を部品に分けたり、紙面上で手動移動したりする必要はありません。

## 起動

Windows で `起動.bat` をダブルクリックします。Python 3.9 と tkinter が必要です。インターネット接続、追加ソフト、pip は使いません。

最初の画面で次のどちらかを選びます。

- `新しい号を作る`: 保存先となる号フォルダを選びます。
- `続きを開く`: `号情報.json` と `紙面.json` がある号フォルダを選びます。

入力は号フォルダの `項目.json` に保存されます。保存前の内容は `項目_前回.json` に残ります。写真は `写真`、自動作成した印付き原稿は `事務局原稿`、Word は `出力/出力_…` に入ります。以前の原稿や出力は消しません。

## 15の手順

1. はじめに: 新しい号を作るか、続きを開きます。
2. 号の情報: 号数、発行月、発行日を入れます。
3. 議員名簿: 1行に1人を入力し、議長名を指定します。
4. 表紙: 写真説明と特集の題名を入れます。
5. 行政報告: 報告事項ごとに見出しと本文を入れます。
6. 当初予算または決算: 概要と質疑を入れます。
7. 議案と賛否(エクセル): 名簿からひな形を作り、Excelで入力して取り込みます。
8. 審議したこと: 会期を入力し、自動集計された件数を確認します。説明・質疑の議案名はExcelの件名から選べます。
9. 委員会報告: 委員会名、見出し、本文を入れます。
10. 一般質問: Word・メール本文・手書きの原稿を受け付け、議員ごとに題と最大4件の質問を入れます。1人1ページです。
11. 特集: 題と本文を入れます。
12. 最終ページ: 編集後記、自由欄、次回定例会などを入れます。
13. 写真: 誰の・どの記事かを付けてJPEGまたはPNGを追加し、紙面見本をクリックして置きます。
14. 全ページの確認: 未入力、あふれ、余りを確認します。
15. Word出力: 確認用Word、確認リスト、写真配置一覧を出力します。

`次へ`で自動保存します。必須欄が空でも、理由を確認して `空のまま進む` を選べます。左の手順名を押すといつでも戻れます。完了した手順には ✓ が付きます。

## 入力のこつ

- 一覧は `＋追加`、`削除`、`上へ`、`下へ` で整えます。
- 予算・決算の `まとめて貼る` では、`問　` と `答　` で始まる行を自動で分けます。分けられない文章も概要として残ります。
- 行政報告、委員会報告、特集は、入り切らない文章を同じ区分の次ページへ自動で送ります。
- `紙面を見る` で色分けした配置と、あふれ行数・削る字数の目安を確認できます。
- 一般質問の顔写真枠は自動です。実写真を入れる場合は写真手順からページを指定します。

## 議案と賛否のExcel

1. 議員名簿を保存してから、`ひな形を作る`で `.xlsx` の保存先を選びます。同名があっても `_2` のような別名になり、上書きしません。
2. Excelの「議案と賛否」シートで、1行に1件ずつ区分・議案番号・件名・議決結果を入力し、議員列へ `○`（賛成）、`●`（反対）、`欠席`、`議長`を入れます。詳しい書き方は「書き方」シートにあります。
3. `エクセルを取り込む`で保存したファイルを選びます。件数は審議したことへ自動反映され、結果と注意が画面に出ます。元ファイルは変更せず、号フォルダの `賛否` に時刻付きの複製を残します。

画面では○・●を直せません。元データをExcel一つにして、Excelと画面の内容が食い違うのを防ぐためです。直す場合はExcelを直して、もう一度取り込みます。古い `.xls` や `.csv` は、Excelの「名前を付けて保存」でExcelブック `.xlsx` にしてから使います。

## Word・メール・手書きの原稿

- Word: `Word から読み込む`で `.docx` または `.doc` を選びます。問・答の分割結果を原稿と見比べ、`これで入れる`を押します。元ファイルは変更せず、`受け取った原稿`へ複製します。
- メール: 本文を貼り、引用・署名・ヘッダの「外す候補」から外す行だけを選びます。整えた本文と問・答を確認してから取り込みます。貼った元本文も `受け取った原稿`へ保存します。
- 手書き: 紙を見ながら入力欄へ直接打ちます。入力後は `確認用に印刷`で横書きの普通のWordを作り、議員に赤ペンで確認してもらいます。

受付状況は名簿の全員について、未着・入力中・議員確認待ち・確認済みで表示されます。

## 写真

メール添付は一度ファイルとして保存します。紙の写真は複合機で350dpi以上、JPEGでスキャンして追加し、紙は議員へ返します。HEICなどを読めない場合は、写真アプリでJPEGに書き出します。

写真を選び、特大(幅110mm)・大・中・小・顔と説明を指定して紙面見本の置きたい所をクリックします。置いた写真はドラッグできます。見出し・ページ外・別の写真に重なる場合は近い空きへ寄せ、本文は写真をよけて流れ直します。あふれたときは、写真を小さくする、次ページへ送る、本文を削る、のいずれかで直します。一般質問の顔写真は従来どおり印刷所用の自動枠です。

## 字が欠けないかの確かめ(初めて使うパソコンで一度)

`確かめ用の見本を作る.bat` をダブルクリックすると、架空の第998号を作ってフォルダを開きます。`出力` の中の `第998号.docx` を Word で開き、次を見てください。

- 行の端や段の下の字が切れていないか
- 写真のまわりの字が写真に重なっていないか
- 見出しの字が枠からはみ出していないか

欠けていたら、どのページのどの辺りかを担当者(ツールを直す人)に伝えてください。

## 困ったとき

- `合計…ページ` または `奇数` と出る: 一般質問の人数か委員会報告の件数を確認してください。合計は22ページ以内の偶数です。
- `あふれ` と出る: 表示された字数を目安に文章を短くするか、写真を別ページにします。
- 写真を読めない: JPEGまたはPNGへ変換します。
- 原稿の場所や内容が分からない: 前の担当者か局長に確かめます。
- 出力をやり直したい: もう一度出力します。別の `出力_…` フォルダに作られ、前の出力は残ります。

開発時の確認は `python3 -m unittest discover -s tests`、架空の見本出力は `python3 demo_edition.py` です。
