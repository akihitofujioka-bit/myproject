# 議会だより 前年同月号 差し込みツール

**前年の同じ月の議会だより（Word）をそのまま様式にして、文字だけを今年の原稿に入れ替える**道具です。

- 日高村議会だよりは年 4 回（4・7・10・1 月）発行で、毎年の構成がほとんど変わりません
- そこで 4月号は前年の 4月号、1月号は前年の 1月号…というように、**前年の同じ月の号**を様式にします
- 書式・見出しの枠・写真の説明文の枠・表紙・裏表紙は**前年のまま**残り、文字だけが変わります
- 賛否一覧表は **Excel から読み込んで**、「別添１：…賛否」の枠の中に表として入れます
- インターネットには何も送りません。**Python だけで動き、追加の部品は要りません**

`gikai_simple`（かんたん原稿ツール）・`gikai_editor`（多機能版）の出力が
「元の紙面のようにならない」という声から作りました。これらは紙面を一から組み立てますが、
元の議会だよりは文字枠を手で重ねて作られているため、同じ見た目になりませんでした。

---

## 様式にする前年の号

| 今年作る号 | 様式（前年の号） | 主な中身 |
|---|---|---|
| 4月号 | 第198号 | 3月定例会・当初予算・注目する事業 |
| 7月号 | 第199号 | 6月定例会 |
| 10月号 | 第200号 | 9月定例会・決算・議員行政視察研修報告 |
| 1月号 | 第201号 | 12月定例会・特集（新年の抱負） |

発行が済んだら、その号で「様式を登録」し直すと、次の年はその号が様式になります。

## 使いはじめる（Windows 10）

1. **Python を入れる**（<https://www.python.org/downloads/windows/>。
   インストールの最初の画面で「Add Python to PATH」にチェック）。**追加の部品は要りません**
2. **`起動.bat` をダブルクリック**
3. **「様式を登録」** で、4月号～1月号それぞれに前年の号を選ぶ
   - `.doc` を選ぶと、そのパソコンの Word で `.docx` に変換して登録します
     （うまくいかないときは、Word で開いて「名前を付けて保存」→「Word 文書（.docx）」）
   - 登録した様式はツールの `様式` フォルダに写します。元のファイルはそのままです

## 号ごとの流れ

1. **「新しい号を作る」** — 号数・発行日・月号を入れ、フォルダを作る場所を選ぶ
2. **左の一覧から欄を選ぶ** — 右上に前年の文章（見本）が出ます
3. **右下に今年の原稿を書く**
   - 議員から届いた Word（`.docx`／`.doc`）やテキストは「Word・テキストを取り込む」でカーソルの位置に入ります
   - 前年の文を少し直すだけなら「↓ 前年の文を写す」を押してから直す
   - 書き始めると、その欄は自動で「今年の原稿」になります
4. **賛否一覧表** — 「別添１：…賛否」の枠を選び、「Excel の賛否表を選ぶ」
5. **「Word を作る」** — `出力/第○号.docx` ができ、気になるところの一覧が出ます

### 1 号 = 1 フォルダ

```
第205号/
  号情報.json     号数・発行日・月号
  様式.docx       号を作ったときに写した前年の号（あとで様式を登録し直しても、この号は変わらない）
  差し込み.json   欄ごとの内容
  別添/           賛否表の Excel など、印刷所に渡すもの
  出力/           第205号.docx
```

フォルダごとコピーすれば、別のパソコンや次の担当者に引き継げます。

## 欄の種類と状態

様式を開くと、文書を頭から読んで**差し込み欄**に分けます（第201号で 195 欄）。

| 種類 | 何か |
|---|---|
| 本文 | 空行で区切られたひとまとまりの段落 |
| 見出し | 大きい字の 1 行（「防災訓練」など） |
| 見出しの升 | 1 升の表で作った見出し（「行政報告（要旨）」など） |
| 枠（縦）／枠（横） | 文字枠。区分の大見出し・質問題・写真の説明文・囲み記事 |
| 名前（1字ずつ） | 「　長／　村／郎／太／田／山」のように 1 字ずつの行で、縦書きの紙面に名前を横に並べたもの。**「山田太郎　村長」と 1 行で書けば、ツールが 1 字ずつに組み直します** |

| 印 | 状態 | Word では |
|---|---|---|
| ✎ | 今年の原稿 | 書いた文に入れ替わる |
| ・ | 前年のまま（はじめはすべてこれ） | 前年の文のまま、**黄色の蛍光ペン**の印が付く |
| ＝ | 毎号同じ | 前年の文のまま、印なし（発行元・再生紙の断り書きなど） |
| ✕ | 空にする | 文を消す（本文は空行で埋めて、以降の位置を保つ） |
| ▦ | 賛否表 | Excel の賛否表を枠の中に入れる |

**表紙の号数と発行日は自動で直します**（「第２０１号」→「第２０５号」）。

### 書き方の決まり

- 数字: 縦書きの欄では、1 桁は全角・2 桁以上は半角にそろえ、2～3 桁は**縦中横**（立てて 1 字分）にします（前年の号と同じ）
- ふりがな: `｜山田《やまだ》` と書くと、Word のルビになります
- 「質問」「答弁」で始まる行は、前年の同じ言葉で始まる行の書式（太字など）を引き継ぎます

## 紙面がずれないしくみ（大事）

前年の号は**改ページが 1 つも無く**、ページの区切りも枠の位置も「空行の数」で手作業で合わせてあります。
そのため記事の長さが変わると、そのままでは以降の記事と枠が食い違います。

このツールは、**記事が前年より何行長く（短く）なったかを数え、すぐ後ろの空行を同じ行数だけ減らし（足し）て**、
以降の記事の位置を保ちます。

- 1 行の字数は紙面から計算します（本文 11pt で 1 行 12 字。第201号の画面で数えた値と一致）
- すぐ後ろの空行が足りないときは、「Word を作る」のあとに**どの記事が約何行あふれたか**を知らせます
- 文字枠に入りきらないかもしれない欄も知らせます（目安）
- **行数は目安です。** 仕上げは Word で整えてください

## 前年に無い記事を足す・要らない枠を消す

- **この欄を複製** — 同じ形の欄をもう 1 つ作ります。本文は元の記事の直後に、
  文字枠は 10mm 下にずらして複製します（Word で正しい場所へ動かしてください）
- **この枠を消す** — 文字枠を、できあがる Word から消します（様式は変わりません）
- 一般質問の議員が前年より多いときは、その議員の分の欄（名前・質問題・本文）を 1 つずつ複製します

## 賛否一覧表

- 事務局の Excel（「議決結果」の見出しがある形。第204号の `議案と賛否第204号.xlsx` で確認）を読みます
- 行・列の位置は決め打ちせず、「議決結果」の見出しを手がかりに、議員名・区分・件名・○●・結果を読み取ります
- Excel のふりがなは混ぜません
- 表は**横書きの枠の中**に入れるので、Excel と同じ向き（議案が上から下、議員名が左から右）で出ます
- 枠は紙面の幅いっぱいに広げ、**ページの下端**にそろえます（前年の号で表の場所として空けてある段）
- 表が 1 段（約 48mm）より高いときは、上の段と重なることを知らせます
- 古い `.xls` は読めません。Excel で「Excel ブック（.xlsx）」として保存し直してください

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.pyw` | 画面（Tkinter） |
| `core.py` | 様式の読み取り、欄への差し込み、空行での位置合わせ、号フォルダ |
| `vote_docx.py` | 賛否表を Word の表にする |
| `xlsx_vote.py` | Excel の賛否表を読む（標準ライブラリだけ） |
| `doc97.py` | 旧 `.doc` の原稿から文字を取り出す（`gikai_simple` から複製） |
| `tests/test_core.py` | 自動テスト |
| `起動.bat` | Windows で起動（Shift_JIS・CRLF で保存。UTF-8 にすると化ける） |

## テスト

```
python -m unittest discover -s tests
```

`.docx` の入ったフォルダを `GIKAI_TEMPLATE_DIR` に指定します。

## 確かめたこと・まだ確かめていないこと

- **確かめた（Mac の Word で開いて目で見た）**: 第198～201号を様式にして作った Word が壊れずに開くこと、
  本文の入れ替え・縦中横・1 字ずつの名前・表紙の号数と発行日・黄色の印・賛否表の見た目
- **まだ**: Windows の Word での見た目、`.doc` を Windows の Word で自動変換する機能（PowerShell 経由）、
  `起動.bat`。役場のパソコンで一度試してください

## 変えたくなったら

- 前年のままの欄の印の色 → `core.py` の `KEEP_HIGHLIGHT`
- 数字の全角・半角の自動変換を止める → `core.py` の `NUMBERS_TATEGAKI = False`
- 画面で区切りに使う見出しの大きさ → `core.py` の `GROUP_HEAD_PT`
- 賛否表の字の大きさ・列の幅 → `vote_docx.py` の `BODY_PT`・`MEMBER_COL_MM` など
