# 議会だより 前年同月号 差し込みツール

**前年の同じ月の議会だより（Word）をそのまま様式にして、文字だけを今年の原稿に入れ替える**道具です。

- 日高村議会だよりは年 4 回（4・7・10・1 月）発行で、毎年の構成がほとんど変わりません
- そこで 4月号は前年の 4月号、1月号は前年の 1月号…というように、**前年の同じ月の号**を様式にします
- 書式・見出しの枠・写真の説明文の枠・表紙・裏表紙は**前年のまま**残り、文字だけが変わります
- 賛否一覧表は **Excel から読み込んで**、「別添１：…賛否」の枠の中に表として入れます
- インターネットには何も送りません。**Python だけで動き、追加の部品は要りません**

`gikai_simple`（かんたん原稿ツール）・`gikai_editor`（多機能版）の出力が
「元の紙面のようにならない」という声から作りました。これらは紙面を一から組み立てますが、
元の議会だよりは文字枠を手で重ねて作られているため、同じ見た目になりませんでした。

---

## 様式にする前年の号

| 今年作る号 | 様式（前年の号） | 主な中身 |
|---|---|---|
| 4月号 | 第198号 | 3月定例会・当初予算・注目する事業 |
| 7月号 | 第199号 | 6月定例会 |
| 10月号 | 第200号 | 9月定例会・決算・議員行政視察研修報告 |
| 1月号 | 第201号 | 12月定例会・特集（新年の抱負） |

発行が済んだら、その号で「様式を登録」し直すと、次の年はその号が様式になります。

---

## 使いはじめる（Windows 10）

1. **Python を入れる**（<https://www.python.org/downloads/windows/>。
   インストールの最初の画面で「Add Python to PATH」にチェック）。**追加の部品は要りません**
2. **`起動.bat` をダブルクリック**
3. **「様式を登録」** で、4月号～1月号それぞれに前年の号を選ぶ
   - `.doc` を選ぶと、そのパソコンの Word で `.docx` に変換して登録します
     （うまくいかないときは、Word で開いて「名前を付けて保存」→「Word 文書（.docx）」）
   - 登録した様式はツールの `様式` フォルダに写します。元のファイルはそのままです

## 号ごとの流れ

1. **「新しい号を作る」** — 号数・発行日・月号を入れ、フォルダを作る場所を選ぶ
2. **左の一覧から欄を選ぶ** — 右上に前年の文章（見本）が出ます
3. **右下に今年の原稿を書く**
   - 議員から届いた Word（`.docx`／`.doc`）やテキストは「Word・テキストを取り込む」でカーソルの位置に入ります
   - 前年の文を少し直すだけなら「↓ 前年の文を写す」を押してから直す
   - 書き始めると、その欄は自動で「今年の原稿」になります
4. **賛否一覧表** — 「別添１：…賛否」の枠を選び、「Excel の賛否表を選ぶ」
5. **「Word を作る」** — `出力/第○号.docx` ができ、気になるところの一覧が出ます

### 1 号 = 1 フォルダ

```
第205号/
  号情報.json     号数・発行日・月号
  様式.docx       号を作ったときに写した前年の号（あとで様式を登録し直しても、この号は変わらない）
  差し込み.json   欄ごとの内容
  別添/           賛否表の Excel など、印刷所に渡すもの
  出力/           第205号.docx
```

フォルダごとコピーすれば、別のパソコンや次の担当者に引き継げます。

## 欄の種類と状態

様式を開くと、文書を頭から読んで**差し込み欄**に分けます（第201号で 195 欄）。

| 種類 | 何か |
|---|---|
| 本文 | 空行で区切られたひとまとまりの段落 |
| 見出し | 大きい字の 1 行（「防災訓練」など） |
| 見出しの升 | 1 升の表で作った見出し（「行政報告（要旨）」など） |
| 枠（縦）／枠（横） | 文字枠。区分の大見出し・質問題・写真の説明文・囲み記事 |
| 名前（1字ずつ） | 「　長／　村／郎／太／田／山」のように 1 字ずつの行で、縦書きの紙面に名前を横に並べたもの。**「山田太郎　村長」と 1 行で書けば、ツールが 1 字ずつに組み直します** |

| 印 | 状態 | Word では |
|---|---|---|
| ✎ | 今年の原稿 | 書いた文に入れ替わる |
| ・ | 前年のまま（はじめはすべてこれ） | 前年の文のまま、**黄色の蛍光ペン**の印が付く |
| ＝ | 毎号同じ | 前年の文のまま、印なし（発行元・再生紙の断り書きなど） |
| ✕ | 空にする | 文を消す（本文は空行で埋めて、以降の位置を保つ） |
| ▦ | 賛否表 | Excel の賛否表を枠の中に入れる |

**表紙の号数と発行日は自動で直します**（「第２０１号」→「第２０５号」）。

### 書き方の決まり

- 数字: 縦書きの欄では、1 桁は全角・2 桁以上は半角にそろえ、2～3 桁は**縦中横**（立てて 1 字分）にします（前年の号と同じ）
- ふりがな: `｜山田《やまだ》` と書くと、Word のルビになります
- 「質問」「答弁」で始まる行は、前年の同じ言葉で始まる行の書式（太字など）を引き継ぎます

## 紙面がずれないしくみ（大事）

前年の号は**改ページが 1 つも無く**、ページの区切りも枠の位置も「空行の数」で手作業で合わせてあります。
そのため記事の長さが変わると、そのままでは以降の記事と枠が食い違います。

このツールは、**記事が前年より何行長く（短く）なったかを数え、すぐ後ろの空行を同じ行数だけ減らし（足し）て**、
以降の記事の位置を保ちます。

- 1 行の字数は紙面から計算します（本文 11pt で 1 行 12 字。第201号の画面で数えた値と一致）
- すぐ後ろの空行が足りないときは、「Word を作る」のあとに**どの記事が約何行あふれたか**を知らせます
- 文字枠に入りきらないかもしれない欄も知らせます（目安）
- **行数は目安です。** 仕上げは Word で整えてください

## 原稿を見出しと本文に分けて、欄へ振り分ける

議員から届く Word には、見出しと本文がいくつも続けて書かれています。1 つの欄に取り込んで
1 つずつ写し直すのは手間なので、**まとまりに分けて、欄へまとめて振り分け**られます。

1. 原稿の最初の見出しを入れる欄（例: 行政報告の最初の見出し）を左の一覧で選ぶ
2. 「Word を取り込んで、見出しと本文を欄に振り分ける」で原稿を選ぶ
3. 確認の画面で「見出し／本文」と「入れる欄」を確かめ、違っていたら直す
   （同じ欄を 2 つ以上選ぶとつなげて入れる。「（入れない）」も選べる）
4. 「この振り分けで入れる」。入れた欄は ✎（今年の原稿）になる。すでに今年の原稿が
   書いてある欄は、置き換える前に一覧で確かめる

**見出しの見分け方**

| 原稿 | 見出しとみなすもの |
|---|---|
| `.docx` | 「見出し」スタイル（アウトラインのレベル付き）、段落の字がすべて太字、本文より 2pt 以上大きい字（いずれも 40 字までで「。」で終わらない行） |
| `.doc`・`.txt`（書式が取れない） | 25 字までで「。」などで終わらず、後ろに長い本文が続く行。「質問」「答弁」や「(1)」で始まる行は見出しにしない |

見出しでない段落は、次の見出し（または空行）までを 1 つの本文にします。

**欄の選び方**: 見出しは「見出し」「見出しの升」と、大きい字（13pt 以上）の文字枠
（区分の大見出し・一般質問の質問題・「人事」「条例」）へ、本文は「本文」の欄へ、紙面の順に入れます。
写真の説明文の枠と名前（1字ずつ）の欄は飛ばします。

前から順に詰めるだけだと 1 か所ずれると後ろがすべてずれるため、**全体でいちばん合う組み合わせ**
を探します（原稿の本文が細かく分かれていれば前の欄につなげ、合う欄の無い見出しは入れない）。
前年と同じ言葉で始まる見出し（毎年ある「防災訓練」など）は目印として優先します。
第201号の行政報告で試すと 26 のまとまりのうち 22 が正しい欄に入り、外れた 4 つは
様式の読み取りのくっつき（「分ける」で直せる）などでした。**案なので、必ず確認の画面で確かめてください。**

## 読み取りを直す（種類を変える・欄を分ける・つなげる）

ツールは**空行を区切り**にして欄に分け、**字の大きさや行の形**で種類を見分けます。
前年の号の作り方しだいで、見出しと本文が 1 つの欄にくっついたり、1 つの記事が写真の
場所の空行で 2 つに分かれたりします。そのときは画面の「読み取りを直す・欄を組み替える」で直します。

| 操作 | 使う場面 | どうなるか |
|---|---|---|
| **種類**を選び直す | 見出しなのに「本文」と出ている、など | 本文／見出し／名前（1字ずつ）から選ぶ。**出来上がりの処理にも効く**。見出しは欄の中でいちばん大きい字の書式で入り、名前（1字ずつ）は 1 行で書いた名前を 1 字ずつの行に組み直す。「（自動で見分ける）」で元に戻る |
| **分ける** | 見出しと本文、2 つの記事が 1 つの欄になっている | 前年の文章の、後ろの欄の 1 行目にしたい行の行頭にカーソルを置いて押す。前後とも前年の書式のまま別の欄になる |
| **つなげる** | 1 つの記事が 2 つの欄に分かれている | 前の欄を選んで押す。本文どうし・同じ枠の中どうしだけつなげられる。間の空行（写真の場所）は、今年の原稿を入れると記事のすぐ後ろへ回る |
| **組み替えを1つ戻す** | やり直したい | 分ける・つなげる・複製・枠を消すを、新しいものから順に取り消す |

- 文字枠・表の升目・本文は Word の中で入れ物が違うので、**互いに種類を変えることはできません**
  （文字枠の縦書き・横書きも Word の枠の設定で決まります）
- 組み替えは号のフォルダの `差し込み.json` に**やった順に記録**し、開くたびに前年の号から
  やり直します。前年の号そのものは書き換えません

## 前年に無い記事を足す・要らない枠を消す

- **この欄を複製** — 同じ形の欄をもう 1 つ作ります。本文は元の記事の直後に、
  文字枠は 10mm 下にずらして複製します（Word で正しい場所へ動かしてください）
- **この枠を消す** — 文字枠を、できあがる Word から消します（様式は変わりません）
- 一般質問は、欄を複製するより次の「一般質問を原稿から組み直す」を使うほうが早く、きれいです

## 原稿から組み直す（行政報告・審議したこと・委員会報告・一般質問・特集）

行政報告・審議したこと・閉会中の委員会活動報告・一般質問・特集は、記事の数や議員の人数が毎回違います。前年の欄に
差し込む方式では数が合わないので、**前年の号から「部品」を取り出して、今年の原稿に合わせて並べ直します**。

1. 画面上の「原稿から組み直す区分」で、区分ごとに「**原稿を選ぶ…**」（`gikai_simple` の
   `02_行政報告.txt`・`03_審議したこと・決まったこと.txt`・`04_閉会中の委員会活動報告.txt`・
   `05_一般質問.txt`・`06_特集.txt`、または届いた Word）。
   原稿は毎回読み直すので、あとから原稿を直しても反映されます
2. 「**読み取りを確かめる・直す**」で、行ごとの種類（見出し・名前・本文・写真・使わない）を確かめる。
   違っていたら行を選んで種類を直す。直した種類は号のフォルダに覚えます
3. 「Word を作る」。前年のその区分の欄（一覧で「⇄」の印）は使わず、部品で組み直します。
   原稿を選ばなかった区分は、これまでどおり前年の欄に差し込みます

### 行政報告・委員会報告の原稿の書き方

```
■防災訓練                     ← 見出し。■ を付けるか、本文より短い行（句点で終わらない）
11月９日に防災訓練を行い…
【写真】kunren.jpg｜中｜説明
```

```
総務常任委員会                 ← 見出し（委員会名）。「経済建設厚生」「常任委員会」の 2 行でもよい
委員長　山田太郎               ← 「山田太郎委員長」でもよい。名前も「委員長」も 1 字ずつの行で組む
11月26日（水）午後２時より     ← 日時・課長名の行は、短くても見出しにしない
佐藤総務課長
　職員の採用試験では…
```

- 行政報告の頭（「行政報告（要旨）」の表と村長の名前）は組み直さず、前年の欄に差し込みます
- 見出しは前年の 14pt の見出しの書式、本文は前年の本文の書式で組みます
- 組み直す範囲の中にある前年の写真の説明の枠は消します。ただし、**ほかの区分の見出しの枠は残します**
  （第201号の「閉会中の委員会活動報告」は最初の委員会の名前の行に、第200号の「一般会計決算額」は
  行政報告の最後の本文につなぎ留めてあるため）
- 区分の終わりは、次の大見出し・「○月議会では」の枠・「◎」で始まる議案の行で見分けます
  （第199号の「審議したこと」には大きな字の見出しが無いため）

### 審議したことの原稿の書き方

```
人事                           ← 区分（人事・条例・予算・報告・承認・同意・その他・議員提出議案 など）
◎教育委員の任命に同意した。
候補者
山田花子氏
予算
◎令和９年度一般会計補正予算（第２号）
質疑
問　防災倉庫の整備費の内容は。
答　備蓄品を置く倉庫を２か所に建てる。
```

- 区分は、前年の区分の小さな枠と同じ字の書式で、**罫線で囲んだ段落**にします（枠のままだと重なり・切れが起きるため）
- 「◎」「問」「答」の行は、前年のそれぞれの行の書式（頭の記号だけ太字など）を写します
- 「○月議会では…計○議案が決まった」の枠、「審議したこと」の大見出し、賛否表の枠（別添）は
  組み直さず、前年の欄のまま差し込みます（賛否表は「Excel の賛否表を選ぶ」で）
- 始まりは「○月議会では」の枠でも見分けます（第198・199号は大見出しの字が読み取れないため）

### 特集の原稿の書き方

特集はテーマも組み方も毎年違う（第198号: 二十歳のつどい・入学おめでとう、第200号: 金婚、第201号:
新年の抱負）ので、紙面を組み直すのではなく、**前年の人ごとの枠に、今年の人を紙面の順に入れます**。

```
特集　新年の抱負を聞きました   ← 使わない（見出しの枠は前年の欄に差し込む）
｜山田《やまだ》 太郎さん・花子さん  ← 「さん」で終わる行から 1 人（1 組）ぶん。ふりがなは ｜親字《よみ》
山田農園                       ← 名前の直後の短い行は所属
新年あけましておめでとうございます。…
```

- 人ごとの枠 = 一般質問より後ろ・編集後記より前にある、縦書きで「さん」の付いた名前のある枠（第200・201号）
- 枠が余れば消し、足りなければ入らなかった人の名前を知らせます（Word で枠を複製して入れてください）
- 枠に入りきらないかもしれない人も、目安を知らせます
- 人ごとの枠で組まれていない号（第198・199号）は、枠に入れられないと知らせ、前年の形のまま残します
  （その号は、これまでどおり前年の欄に差し込んでください）

### 一般質問の原稿の書き方

```
一般質問に３氏が立つ          ← 人数は数えて入れ直すので、無くても違っていてもよい
防災対策について              ← 「質問」の直前の短い行が題（名前より前でも後でもよい）
山田太郎議員                  ← 「○○議員」だけの行で、1 人ぶんが始まる
【写真】yamada.jpg｜顔         ← gikai_simple と同じ写真の行（大きさ: 表紙・大・中・小・顔）
質問　避難所の備蓄は十分か。
答弁　佐藤総務課長
　備蓄品は毎年見直しており…
公共交通の                    ← 2 行に分けた題も 1 つの題としてまとめる
今後について
質問　…
```

### 組み直しの中身

| 部品 | 様式のどこから | 組み直すとき |
|---|---|---|
| 議員の最初の題 | 題の表・文字枠の中の大きな字（18〜28pt） | **罫線で囲んだ段落**にして本文の流れに置く。囲みの長さは題の長さに合わせ、1 段に入らなければ折り返す |
| 名前 | 1 字ずつの行（「議員」まで 1 字ずつそろった人を見本にする） | 後ろの字から 1 字ずつの行で組む |
| 2 問目からの題 | 14pt の段落 | 同じ書式で。前後に空行 1 行 |
| 質問・答弁・本文 | 「質問」「答弁」で始まる段落・本文の段落 | 頭の言葉だけ太字などの書式も写す。数字の縦中横も付ける |
| 写真 | （前年の空行） | 赤字で「【写真】ファイル名（中・幅55mm）説明」と書き、写真の幅ぶんの空行を空ける |

- 題は、様式の**表や文字枠をそのまま使いません**。前年の題の長さで寸法が決めてあり、本文の外に浮かせて
  あるため、そのまま使うと本文と重なる・段の境目で切れる・紙の端からはみ出すことを、第198・201号で
  確かめたためです。段落にしておけば、Word が本文と同じように段・ページを送ります
- 題と名前には「次の段落と同じ段に置く」を付けているので、**題だけが段の最後に取り残されません**

### 後ろの記事がずれないしくみ

様式の本文は表紙のあとから 1 本の流れ（縦書き 5 段）で、文字枠はすべて段落につなぎ留めてあります
（ページに固定した枠はありません）。組み直した一般質問の長さに合わせて、空行を足して
**前年との差を「ちょうど何ページ分」にそろえる**ので、後ろの記事は前年と同じページ内の位置に来ます。

- 前年より短くて 1 ページ以上余るときは、空白のページを作らず、**ページごと詰めます**（全体のページ数が減ります）
- 前年より長いときは、後ろの記事をページ単位で送ります（全体のページ数が増えます）
- 印刷は 4 ページ単位のことが多いので、ページ数が変わったと報告されたら、原稿の長さかほかの記事で調整してください
- 行数は見積もり（Mac の Word で第201号を測った値: 1 段 = 11pt の行で 36 行）です。**Word で必ず確かめてください**

## 賛否一覧表

- 事務局の Excel（「議決結果」の見出しがある形。第204号の `議案と賛否第204号.xlsx` で確認）を読みます
- 行・列の位置は決め打ちせず、「議決結果」の見出しを手がかりに、議員名・区分・件名・○●・結果を読み取ります
- Excel のふりがなは混ぜません
- 表は**横書きの枠の中**に入れるので、Excel と同じ向き（議案が上から下、議員名が左から右）で出ます
- 枠は紙面の幅いっぱいに広げ、**ページの下端**にそろえます（前年の号で表の場所として空けてある段）
- 表が 1 段（約 48mm）より高いときは、上の段と重なることを知らせます
- 古い `.xls` は読めません。Excel で「Excel ブック（.xlsx）」として保存し直してください

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.pyw` | 画面（Tkinter） |
| `core.py` | 様式の読み取り、欄への差し込み、空行での位置合わせ、号フォルダ |
| `flow.py` | 行政報告・審議したこと・委員会報告・一般質問を様式の部品で組み直し、特集は人ごとの枠に入れる |
| `vote_docx.py` | 賛否表を Word の表にする |
| `xlsx_vote.py` | Excel の賛否表を読む（標準ライブラリだけ） |
| `doc97.py` | 旧 `.doc` の原稿から文字を取り出す（`gikai_simple` から複製） |
| `tests/test_core.py` | 自動テスト |
| `起動.bat` | Windows で起動（Shift_JIS・CRLF で保存。UTF-8 にすると化ける） |

## 確かめたこと・まだ確かめていないこと

- **確かめた（Mac の Word で開いて目で見た）**: 第198～201号を様式にして作った Word が壊れずに開くこと、
  本文の入れ替え・縦中横・1 字ずつの名前・表紙の号数と発行日・黄色の印・賛否表の見た目
- **確かめた（審議したこと・特集）**: 第198〜201号の 4 つとも、架空の原稿で 5 区分すべてを通して
  Word が壊れずに開くこと（特集は第200・201号だけ枠に入り、第198・199号は知らせて前年のまま）。
  第201号は Mac の Word で、審議の区分の囲み・◎・問答、特集の枠に名前とふりがなが入ることを確かめた。
  なお Mac の Word では、前年の号そのものでも特集の見出しの枠がページをまたいで見える（Windows との
  字の幅の違いと思われる）。役場の Word で確かめてください
- **確かめた（行政報告・委員会報告の組み直し）**: 第198〜201号の 4 つとも、架空の原稿で 3 区分すべてを
  組み直した Word が壊れずに開くこと。第200・201号は Mac の Word で見た目も確かめた（見出し・委員長の
  名前・写真の赤字、ほかの区分の見出しの枠が残ること）
- **確かめた（一般質問の組み直し）**: 第198〜201号の 4 つとも、架空の原稿（3 人・題 6 件）で組み直した
  Word が壊れずに開くこと。第198・201号は Mac の Word で見た目も確かめた（題の囲み・1 字ずつの名前・
  2 問目の題・写真の赤字・後ろの記事がページ単位で詰まること）
- **まだ**: 本物の一般質問の原稿での読み取りの当たり具合、Windows の Word での見た目、`.doc` を Windows の Word で自動変換する機能（PowerShell 経由）、
  `起動.bat`。役場のパソコンで一度試してください

## 変えたくなったら

- 前年のままの欄の印の色 → `core.py` の `KEEP_HIGHLIGHT`
- 数字の全角・半角の自動変換を止める → `core.py` の `NUMBERS_TATEGAKI = False`
- 画面で区切りに使う見出しの大きさ → `core.py` の `GROUP_HEAD_PT`
- 賛否表の字の大きさ・列の幅 → `vote_docx.py` の `BODY_PT`・`MEMBER_COL_MM` など
