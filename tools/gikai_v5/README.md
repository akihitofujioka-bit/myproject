# 議会だより編集ツール V5

## 起動のしかた

Windows で `起動.bat` をダブルクリックします。最初に「新しい号」または「号を開く」を選びます。

## 作業の流れ

1. ①号を作る: 号数、月、発行日、人数、ページ数を入れます。
2. ②原稿を入れる: ページを選び、「原稿を入れる」で原稿ファイルを選びます。
3. ③並べる: 写真や大見出しをドラッグします。緑は置ける場所、赤は置けない場所です。
4. ④確かめる: 「確かめる」で未入力やあふれを確認します。
5. ⑤書き出す: 「Word に書き出す」を押します。画面に保存先が表示されます。

操作を間違えたときは「元に戻す」を押します。「やり直す」で戻す前の状態にできます。

## 号フォルダの中身

- `号情報.json`: 号数、発行日、人数など
- `紙面.json`: ページの割り当て、写真の場所、操作の記録
- `原稿`: 取り込んだ原稿の写し。元の原稿は書き換えません
- `写真`: 原稿から取り出した写真の写し
- `出力`: 完成した Word、確認リスト、使用した写真
