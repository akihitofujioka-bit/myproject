# 議会だより編集ツール V5

## 起動のしかた

Windows で `起動.bat` をダブルクリックします。最初に「新しい号」または「号を開く」を選びます。

- 「新しい号」: 号数と月などを入れ、新しい紙面を作ります。
- 「号を開く」: 保存した号フォルダを選び、前の作業を続けます。
- 画面上部の「いまやること」に、次の操作が表示されます。

## 作業の流れ

1. ①号を作る: 号数、月、発行日、人数、ページ数を入れます。
2. ②原稿を入れる: ページを選びます。表紙・「審議したこと・決まったこと」・最終ページは書き込み式です。右の「ページ」タブの「入力欄を開く」で直接書きます。ほかのページは同じタブの「原稿を入れる」で原稿ファイルを選ぶか、「書いて直す」でツールの中に書きます。
3. ③並べる: 写真はすべて号フォルダの `写真` へコピーします。右の「写真」タブで写真を選び、紙面の置きたい所をクリックするか、一覧から紙面へドラッグします。緑は置ける場所、赤は置けない場所です。表紙と編集後記も同じ手順です。置いた写真は「部品」タブで大きさ・説明を直したり、紙面から外したりできます。
4. ④確かめる: 種類が違う部品は、紙面または一覧で選び、右の「部品」タブの「種類を直す」で正しい種類を押します。その後、タブの下にある「確かめる」で未入力やあふれを確認します。
5. ⑤書き出す: 右側のタブの下にある「Word に書き出す」を押します。画面に保存先が表示されます。

操作を間違えたときは、右側のタブの下にある「元に戻す」を押します。「やり直す」で戻す前の状態にできます。

## チャットで操作する

- 右の「チャット」タブへ決まった言い方を入力します。内容を読み取ると「こうします」と表示され、[実行]を押したあとに操作します。[やめる]を押せば紙面は変わりません。
- ページ: `次のページ`、`前のページ`、`5ページ`、`一般質問の2人目`、`表紙`、`最終ページ`
- 写真: `写真2を小さく`、`写真2を大に`、`写真2を外す`、`写真2を戻す`、`この写真を顔に`
- 部品: `3番を答弁に`、`この部品を質問に`、`7番は中見出し`
- 移動: `写真1を2段目の左へ`、`写真1を3段目の右端へ`
- その他: `元に戻して`、`やり直し`、`確かめて`、`書き出し`、`あふれているページは？`、`未入力のページは？`、`使い方`
- 全角・半角数字と漢数字を使えます。読み取れないときは推測で操作せず、言い方の例を表示します。このチャットは AI やインターネットを使いません。

## 写真を置く

- 写真ファイルは号フォルダの `写真` だけに置きます。エクスプローラーでコピーしたあとは「写真」タブの「読み直す」を押します。「写真を追加」でも複数枚をコピーできます。
- PNG は小さな見本を表示します。JPEG はファイル名と画素数を表示します。HEIC などは JPEG か PNG に変えてください。
- 写真を選んで紙面をクリックします。一般質問は最初から「顔」、ほかは「中」の大きさです。表紙は表紙写真の場所、最終ページは編集後記の写真の場所へ入り、編集後記は2枚までです。
- 置いた直後に本文を流し直します。別の写真や見出しに重なる場所には置けません。

## ツールの中で原稿を書く

- 右の「ページ」タブの「書いて直す」を押すと、事務局原稿を書く窓が開きます。
- 「大見出し」「中見出し」「問」「答」「本文」「写真」のボタンで、今の行の先頭へ印を入れます。
- 写真ボタンで選んだ画像は号フォルダの `写真` へ写し、写真の印を原稿へ入れます。
- 入力中も紙面の見本と、あふれ・余りが更新されます。入力欄では `Ctrl+Z` と `Ctrl+Y` で元に戻す／やり直すことができます。
- 保存すると `事務局原稿/ページ番号_区分.txt` に UTF-8 で残り、そのページの原稿になります。取り込んだ原稿を書き直しても、元のファイルは変更しません。

## 書き込み式ページ

- 表紙: 特集の題名を入力します。写真と説明は「写真」タブから置けます。入力欄に残っている写真欄も同じ写真を示します。号数・発行日・特集ページ番号は号情報とページ割りから自動で入ります。
- 審議ページ: 種類ごとの件数、印付きの本文、賛否表を入力します。本文では `【区分】予算`、`◎議案名`、`質疑`、`問　…`、`答　…` の印を使います。
- 最終ページ: 編集後記、自由欄、次回定例会を入力します。写真は「写真」タブから編集後記の段へ0～2枚置けます。入力欄に残っている写真欄も同じ写真を示します。議長名は「設定」から自動で入ります。
- 賛否表の印はボタンを押すたびに、空欄 → ○ → ● → 議長 → 欠席の順に変わります。
- 「設定」で議員名簿（賛否表の列順）、議長名、委員会名を保存します。設定が無くても起動できます。
- 右の「ページ」タブの「前の号から写す」は、決まり文句や自由欄の構成を残し、日付・件数・賛否の印・編集後記など号ごとの内容を空に戻します。

## 画面の印・色・札

- ページの ○ は原稿が未入力、✓ はできたページ、！ は紙面からあふれたページです。
- 部品の ✓ は確かな判断、？ は確認が必要な推測です。
- 問・答・大見出しなど、部品の種類を背景色と右上の札で示します。？付きの札と点線の枠は推測された部品です。
- 紙面は「拡大 ＋」「縮小 −」で3段階に変えられます。
- 画面の「使い方」を押すと、この説明をいつでも確認できます。

## 号フォルダの中身

- `号情報.json`: 号数、発行日、人数など
- `紙面.json`: ページの割り当て、置いた写真のファイル名・場所・大きさ・説明、操作の記録
- `設定.json`: 議員名簿、議長名、委員会名（ツールのフォルダに置き、Gitには含めません）
- `原稿`: 取り込んだ原稿の写し。元の原稿は書き換えません
- `事務局原稿`: ツールの中で書いて保存した印付きテキスト
- `写真`: 事務局が置く写真と、原稿から取り出した写真の写し。写真の置き場はここだけです
- `出力`: 完成した Word、写真配置一覧、確認リスト、使用した写真。350dpi未満と200dpi未満の写真は注意を表示します
