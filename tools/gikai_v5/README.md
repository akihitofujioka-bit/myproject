# 議会だより編集ツール V5

## 起動のしかた

Windows で `起動.bat` をダブルクリックします。最初に「新しい号」または「号を開く」を選びます。

- 「新しい号」: 号数と月などを入れ、新しい紙面を作ります。
- 「号を開く」: 保存した号フォルダを選び、前の作業を続けます。
- 画面上部の「いまやること」に、次の操作が表示されます。

## 作業の流れ

1. ①号を作る: 号数、月、発行日、人数、ページ数を入れます。
2. ②原稿を入れる: ページを選びます。表紙・「審議したこと・決まったこと」・最終ページは書き込み式です。「入力欄を開く」で直接書き、ほかのページは「原稿を入れる」で原稿ファイルを選びます。
3. ③並べる: 紙面と「このページの部品」で内容を確かめます。写真や大見出しはドラッグで動かせます。緑は置ける場所、赤は置けない場所です。写真は「大・中・小・顔」で大きさを変えられます。
4. ④確かめる: 種類が違う部品は、紙面または一覧で選び、「種類を直す」の正しい種類を押します。その後「確かめる」で未入力やあふれを確認します。
5. ⑤書き出す: 「Word に書き出す」を押します。画面に保存先が表示されます。

操作を間違えたときは「元に戻す」を押します。「やり直す」で戻す前の状態にできます。

## 書き込み式ページ

- 表紙: 表紙写真と説明、特集の題名を入力します。号数・発行日・特集ページ番号は号情報とページ割りから自動で入ります。
- 審議ページ: 種類ごとの件数、印付きの本文、賛否表を入力します。本文では `【区分】予算`、`◎議案名`、`質疑`、`問　…`、`答　…` の印を使います。
- 最終ページ: 編集後記、写真0～2枚、自由欄、次回定例会を入力します。議長名は「設定」から自動で入ります。
- 賛否表の印はボタンを押すたびに、空欄 → ○ → ● → 議長 → 欠席の順に変わります。
- 「設定」で議員名簿（賛否表の列順）、議長名、委員会名を保存します。設定が無くても起動できます。
- 「前の号から写す」は、決まり文句や自由欄の構成を残し、日付・件数・賛否の印・編集後記など号ごとの内容を空に戻します。

## 画面の印・色・札

- ページの ○ は原稿が未入力、✓ はできたページ、！ は紙面からあふれたページです。
- 部品の ✓ は確かな判断、？ は確認が必要な推測です。
- 問・答・大見出しなど、部品の種類を背景色と右上の札で示します。？付きの札と点線の枠は推測された部品です。
- 紙面は「拡大 ＋」「縮小 −」で3段階に変えられます。
- 画面の「使い方」を押すと、この説明をいつでも確認できます。

## 号フォルダの中身

- `号情報.json`: 号数、発行日、人数など
- `紙面.json`: ページの割り当て、写真の場所、操作の記録
- `設定.json`: 議員名簿、議長名、委員会名（ツールのフォルダに置き、Gitには含めません）
- `原稿`: 取り込んだ原稿の写し。元の原稿は書き換えません
- `写真`: 原稿から取り出した写真の写し
- `出力`: 完成した Word、確認リスト、使用した写真
