# 議会だより かんたん原稿ツール

議会だよりの **原稿（文章）と写真の配置指示** を、誰でも同じ手順で作るための道具です。

- 画面は 1 つ。覚える操作は「区分を選んで書く」「写真を選んで入れる」「Word を作る」の 3 つ
- 出力は **原稿の Word（写真入り）** と **写真配置指示書の Word** の 2 つ。印刷所にはこれと写真フォルダを渡す
- 校正・要約・議案の自動解析などは **しません**。Word 上で人が直す前提です
- インターネットに何も送りません（すべてこのパソコンの中で完結します）

同じフォルダにある `gikai_editor`（校正・自動組版まで行う多機能版）や、
`gikai_dayori_v5.8.pyw`（タブ式の編集支援ツール）を **小さく作り直したもの** です。
どちらも残してあります。

## 考え方 — 写真の場所は「原稿の中の 1 行」で表す

写真を入れたい場所に、原稿の中へ次の 1 行を書くだけです。

```
【写真】ファイル名.jpg｜中｜説明文
```

| 部分 | 意味 |
|---|---|
| `ファイル名.jpg` | 「写真」フォルダの中のファイル名 |
| `中` | 大きさ。**大**（幅 80mm）／**中**（55mm）／**小**（38mm）／**顔**（26mm・顔写真）。省略すると 中 |
| `説明文` | 写真の説明（キャプション）。省略可 |

区切りは全角「｜」でも半角「|」でもかまいません。
この行は画面のボタンで入れられますが、メモ帳で手書きしても、消しても、別の場所に動かしても大丈夫です。
**ツールが無くても、原稿ファイルを見れば「どこにどの写真か」が分かる**のが狙いです。

## 1 号 = 1 フォルダ

```
第204号/
  号情報.json                    号数・発行日
  01_表紙.txt                    区分ごとの原稿（紙面の順）
  02_行政報告.txt
  03_審議したこと・決まったこと.txt
  04_閉会中の委員会活動報告.txt
  05_一般質問.txt
  06_特集.txt
  07_裏表紙.txt
  写真/                          写真の原本（印刷所にそのまま渡す）
  出力/                          第204号_原稿.docx、第204号_写真配置指示.docx
  はじめにお読みください.txt
```

このフォルダごとコピーすれば、別のパソコンや次の担当者に引き継げます。

## 使いはじめる

### 必要なもの

- **Python 3.9 以降**（<https://www.python.org/downloads/windows/>。インストール時に「Add Python to PATH」にチェック）
- **python-docx**（Word を作る）と **Pillow**（写真の縮小表示・向き補正）

  ```
  pip install -r requirements.txt
  ```

  インターネットにつながらないパソコンでは、つながるパソコンで
  `pip download -d wheels python-docx Pillow` として作った `wheels` フォルダを持ち込み、
  `pip install --no-index --find-links=wheels python-docx Pillow` で入ります
  （Pillow だけなら `gikai_editor/wheels` にも Windows 用が同梱してあります）。

### 起動

- Windows: `起動.bat` をダブルクリック（または `app.pyw` をダブルクリック）
- macOS / Linux: `python3 app.pyw`

> macOS 付属の Python（Tk 8.5）では画面がうまく描かれません。Mac で使うときは
> python.org の Python 3.12 以降（Tk 8.6 付き）を入れてください。

## 使い方（5 つだけ）

1. **「新しい号を作る」** — 号数と発行日を入れ、フォルダを作る場所を選びます
2. **左の区分を選び、中央に原稿を書く** — 議員から届いた `.docx`／`.doc`／`.txt` は「原稿ファイルを取り込む」で文字だけ貼り付きます
3. **「写真フォルダを開く」** で開いたフォルダに写真を入れ、「写真を読み直す」を押します
4. **写真を選び、大きさと説明を決めて「カーソル位置に入れる」** — 原稿に【写真】行が入ります。使用済みの写真は緑の枠になります
5. **「Word を作る」** — 出力フォルダに 2 つの Word ができます。解像度不足や見つからない写真があれば、その場で一覧が出ます

原稿は、区分を切り替えたとき・Word を作るとき・閉じるときに自動で保存されます。

## 数字の全角・半角

縦書きでは半角の数字が横に寝るため、従来の `.doc`（4 号分）で使われていた規則に自動でそろえます。

| 規則 | 例 |
|---|---|
| 1 桁は全角 | ４人、３月、第８号 |
| 2 桁以上は半角 | 第46回、国道33号、131チーム、2025年 |
| 「－」でつないだ番号はそのまま | 〒７８１－２１９４、℡０８８９－２４－７７７７、本郷６１－１ |
| 表紙・【写真】行は触らない | 第２０４号（題字）、写真のファイル名 |

適用されるのは「原稿ファイルを取り込む」とき、「数字をそろえる」ボタンを押したとき、
「Word を作る」とき（原稿ファイル自体は書き換えません）の 3 か所です。
さらに原稿 Word では、2〜3 桁の半角数字に Word の **縦中横**（数字を立てて 1 文字分に入れる）を掛けるので、
縦書きでも「第46回」「131チーム」が横に寝ません（4 桁以上はそのままです）。
止めたいときは `core.py` の `NUMBERS_TATEGAKI = False` にします。

## 出力される Word

| ファイル | 中身 |
|---|---|
| `第○号_原稿.docx` | 従来の `.doc` と同じ紙面。**表紙は横書き 1 段、本文は縦書き 5 段**（A4、余白 上15・下12・左右15mm、段間 6mm、ＭＳ明朝 10.5pt）。区分ごとに改ページ。【写真】行の場所に **赤い指示文（番号・ファイル名・大きさ・説明）と縮小した写真** が入る（写真は 1 段の高さに収まるよう縮めて貼る。印刷所への大きさの指示は赤字のとおり） |
| `第○号_写真配置指示.docx` | 横書きの写真一覧表（番号・縮小画像・ファイル名・区分・大きさ・説明・解像度の注意）。使っていない写真も末尾に出る |

写真は 350dpi で刷ったときに指定の幅に足りるかを確かめ、足りなければ赤字で「元データをもらってください」と出ます。
（メールで縮小された写真は印刷に使えないことが多いためです）

## 変えたくなったら

- 区分を増やす・名前を変える → `core.py` の `KUBUN`
- 写真の大きさの種類・幅 → `core.py` の `SIZES`
- 表紙の雛形の文面 → `core.py` の `COVER_TEMPLATE`
- 原稿 Word の本文を横書きにする → `core.py` の `TATEGAKI = False`
- 段数・余白・段間・行送り → `core.py` の `DANSU`・`MARGIN_MM`・`DAN_SPACE_MM`・`LINE_SPACING`
- 数字の自動変換を止める／対象外の区分を増やす → `core.py` の `NUMBERS_TATEGAKI`・`NUMBERS_SKIP_KUBUN`
- Word の余白・フォント → `core.py` の `_setup_page`
