# 中継サーバー

「ふたりのメッセージ」（`apps/messenger/`）のための中継役。
**暗号文の入った封筒を、宛先の人が取りに来るまで預かるだけ**のサーバー。

外部ライブラリは使わない。Node.js 18 以降があれば動く。

```
node server/server.mjs
```

## このサーバーが持つもの・持たないもの

| | 内容 |
| --- | --- |
| **持たない** | 本文・写真（端末の中で暗号化されており、開く鍵がそもそも無い） |
| **持たない** | 利用者の秘密鍵、パスワード、電話番号、メールアドレス |
| 持つ | 宛先番号（公開鍵から機械的に決まる32文字）と、その公開鍵 |
| 持つ | 誰から誰へ、いつ、どれくらいの大きさの暗号文が流れたか |

**この「持つ」側は運営者から見える。**利用者に必ず伝えること。

受け取られた封筒はその場で削除する。受け取られないままでも **7日で削除**する（`RETAIN_DAYS` で変更可）。

## 設定（環境変数）

| 変数 | 既定 | 意味 |
| --- | --- | --- |
| `PORT` | `8787` | 待ち受けポート |
| `DATA_FILE` | `server/data/relay.json` | 預かり中の封筒を保存する場所 |
| `RETAIN_DAYS` | `7` | 受け取られないまま消すまでの日数 |
| `ORIGIN` | `*` | 許可する接続元。署名で本人確認するため既定は広くしてある |

## 窓口（API）

すべて、利用者の署名鍵（ECDSA P-256）による署名で本人確認する。パスワードは使わない。
署名の文面には必ず時刻を含め、**5分を過ぎた署名は受け付けない**（使い回しを防ぐため）。

| 窓口 | 用途 |
| --- | --- |
| `GET /health` | 動作確認。登録者数と預かり数を返す |
| `POST /register` | 宛先番号の登録。番号は公開鍵から決まるため、他人を名乗れない |
| `POST /send` | 封筒を預ける。中身（`e`）は文字列のまま扱い、サーバーでは開かない |
| `GET /inbox` | 受け取り（Server-Sent Events）。つないでいる間、届いた封筒が流れる |
| `POST /ack` | 受け取り済みとして削除する |

## 上限

| 項目 | 値 |
| --- | --- |
| 1通の大きさ | 2 MB（写真1枚を見込んだ値） |
| 1人あたりの預かり通数 | 500（超えると古いものから捨てる） |
| 1人あたりの送信数 | 120通/分 |

## 置き場所

常時動いている場所であればどこでもよい。無料枠のある例：

- **Render**（Web Service / Node）：`Build Command` は空、`Start Command` に `node server/server.mjs`。
  無料枠は一定時間で停止するため、最初の1通が届くまでに数十秒かかることがある
- **Fly.io**、**Railway**、自宅のサーバー、庁内のサーバーなど

**必ず `https://` で公開すること。** `http://` では、iPhone / Android のアプリから接続できない。

保存先（`DATA_FILE`）が再起動で消える環境では、預かり中の封筒も消える。
届かなかった分は送り直しになるだけで、鍵や履歴は失われない。
