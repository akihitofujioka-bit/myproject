# 出力テンプレート

そのまま社内に貼れる形にする。見出しは職場の慣習に合わせて `report.config.json` の `template` で差し替え可能。

## 日報

```markdown
# 日報 2026-08-28（金）

## 本日の実績
- （タスク単位で1行1成果。何をして、結果どうなったかまで書く）
- （関連リンクは末尾に `[#123](url)` の形で付ける）

## 会議
- 10:00 〇〇定例 — 決定：△△の方針を〜に変更。自分のアクション：□□を来週水曜まで

## 明日の予定
- （カレンダーの翌営業日の予定 + 未完了タスクから）

## 課題・相談事項
- （ブロックされていること。無ければ「特になし」）
```

## 週報

```markdown
# 週報 2026-08-24 〜 2026-08-28

## サマリ
（3行以内。今週何が前に進んだか、詰まっているものは何か）

## 進捗

### プロジェクト名
- （テーマ単位。日ごとに割らない）
- （数字が出せるものは数字で：PR 5件マージ、対応チケット 8件、など）

### プロジェクト名
- ...

## 来週の予定
- （確定している会議・締切と、着手予定のタスク）

## リスク・課題
- （進行を脅かすもの。無ければ「特になし」）
```

## 末尾に必ず付けるもの

本文の後に、報告書の一部ではないメモとして付ける（コピペ時に外せるよう `---` で区切る）。

```markdown
---
### 確認してほしい点（報告書には含めない）
- （推定で書いた箇所）
- （情報が取れなかったソース）
- （機微情報のため意図的に省いた箇所）
```

## 文体

- 常体（だ・である）ではなく、社内報告で一般的な**簡潔な体言止め・敬体混在**を既定とする。設定 `template.tone` で `formal` / `casual` に切り替え可能
- 「〜させていただきました」のような過剰な敬語は使わない
- 一人称は書かない（「私は」を省く）
