家計簿

レシートを見て合計額だけを入れていく家計簿です。店名から費目を自動で選び、よく行く店はボタン1つで入ります。データはこの端末の中だけに保存され、外部には一切送信しません。はじめての方は、いちばん下の「使い方」をお読みください。

      データの持ち出し・引き継ぎ
      
    
      
      
      
      
      
      
      
    
      
    
      
      「表計算用に書き出す」は表示中の月ぶんを CSV にします。Excel や表計算ソフトでそのまま開けます。
      「明細を取り込む」では、クレジットカードや電子マネーの利用明細（CSV）を読み込めます。ファイルは端末の中だけで読み取り、どこにも送信しません。
      保存した JSON は別の端末やブラウザへ引き継ぐときに読み込んでください（読み込むと今のデータは置き換わります）。
    
      
  
      

  
      
    
      取り込む列を選ぶ
      
    
      
    
      
      
      
        
        
      
      
      
      
        
        
      
      
      
      
        
        
      
      
    
      
    
      
    
      
      
      
    
      
    
      同じ日付・金額・内容の記録がすでにある場合は取り込みません（二重計上を防ぐため）。費目は店名から推定し、分からないものは「未分類」にします。
      
  
      

  
      
    
      設定
      
    
      
      
      
        
        
      
      
      
      
        
        
      
      
      
      
        
      
      
    
      
    
      費目を減らしても、すでに記録した内容の費目名はそのまま残ります。
      
  
      

  
      
    
      使い方
      
    
      
      レシートの合計額だけを記録していく家計簿です。品目ごとの明細は取りません。明細まで記録しようとすると手間が増えて続かなくなるためで、月ごとの傾向をつかむには合計で十分だという考え方によります。
    
      
    
        
      
      • 入力は金額・費目・日付の3つだけです。店名とメモは任意ですが、店名を入れておくと次回から費目を自動で選べるようになります。
        • 
      
      • 同じ店で2回目からは費目が自動で入ります。その店で過去にいちばん多く使った費目を選びます。店名に「スーパー」「薬局」「病院」などが含まれる場合は、初回から推定します。
        • 
      
      • 「よく行く店」のボタンを押すと、店名と費目がまとめて入ります。金額と日付だけ入れれば記録できます。
        • 
      
      • カードや電子マネーの明細は CSV で取り込めます。「明細を取り込む」でファイルを選び、日付・内容・金額がどの列かを指定してください。同じ内容が二重に入らないよう確認してから取り込みます。
        • 
      
      • iPhone アプリでは「レシートを撮る」で合計・日付・店名を自動で入れられます。iPhone 標準の文字認識を使い、写真も文字も端末の外には出しません。読み取り結果は必ず確認してから「記録する」を押してください。うまく読めないときは、明るい場所でレシートを平らにし、枠いっぱいに収めて撮り直してください。
        • 
      
      • 買ったものは、冷蔵庫や備蓄アプリに送れます。レシートを撮ると品目の一覧が出るので、送るものにチェックを付けて「冷蔵庫へ」「備蓄へ」を押してください。品名がそのまま在庫に入るため、バーコードで1つずつ登録する手間が省けます。賞味期限はレシートに載らないので、送った先のアプリで入れてください。「メモに残す」を押すと、品名を家計簿の記録のメモ欄に入れます。
        • 
      
      • レシートのバーコードからは金額を読み取れません。レシートに印字されているのは取引番号で、金額や品目は含まれていないためです。
        • 
      
      • データはこの端末の中だけに残ります。サーバーには送りません。アプリを削除したとき、またはブラウザのサイトデータを消したときは一緒に消えるため、「JSONで保存」で控えを取り、別の端末へ移すときは「JSONから読み込み」を使ってください。
