# 日常アプリ

ブラウザだけで動く単一HTMLのアプリ。サーバーもインストールも不要で、ファイルをダブルクリックすれば開く。

| アプリ | 用途 | ファイル |
| --- | --- | --- |
| 冷蔵庫の在庫・賞味期限管理 | 食材の期限を管理し、食品ロスを減らす | `apps/fridge/index.html` |
| 書類・回覧の期限トラッカー | 提出期限のある書類・回覧・申請を管理する | `apps/docs-tracker/index.html` |

## 使い方

1. 各 `index.html` をブラウザで開く（ダブルクリック、またはブラウザに drag & drop）
2. よく使うならブックマークする。スマートフォンなら「ホーム画面に追加」で単体アプリのように使える

ローカルサーバーで開きたい場合は、リポジトリ直下で次を実行して `http://localhost:8080/apps/fridge/` などにアクセスする。

```
npx http-server . -p 8080
```

## データの保存場所と安全性

- データは**開いたブラウザの localStorage にのみ**保存される。外部への送信は一切行わない（通信するコードを含まない）
- したがって**ブラウザやパソコンが変わるとデータは引き継がれない**。「JSONで保存」で書き出し、移行先で「JSONから読み込み」する
- ブラウザの「閲覧履歴・サイトデータの削除」を実行するとデータも消える。定期的な書き出しを勧める
- シークレットウィンドウでは、閉じた時点でデータが消える
- **共用パソコンでは使わない**。使う場合は終了時にサイトデータを削除する
- 書類トラッカーには、個人が特定できる情報（氏名・住所・個人番号など）を入力しない。書類名は「〇〇申請書（△△課分）」のような表記にとどめる

## 朝のブリーフとの連携

書類トラッカーの「JSONで保存」で書き出したファイルを `data/deadlines.json` として置くと、`/brief`（朝のブリーフ）が今日の締切として拾う。
冷蔵庫アプリの書き出しを `data/fridge.json` に置き、`brief.config.json` の `fridge.enabled` を true にすると、期限が近い食材も1行だけ添えられる。

`data/` の中身は業務情報を含みうるため git 管理対象外にしてある。

## つくりの方針

- 依存ライブラリなし。1ファイル完結。ビルド不要
- 端末の設定に合わせてダークモードに対応
- 画面幅に合わせて可変。スマートフォンでもそのまま使える

## 動作確認

`apps/tests/smoke.mjs` が2つのアプリの主な操作（追加・編集・削除・絞り込み・状態変更・再読込後の保持）を実際のブラウザで確認する。

```
npm i -D playwright && npx playwright install chromium
node apps/tests/smoke.mjs
```

アプリ本体は依存ライブラリなしで動く。Playwright を使うのはこのテストだけ。
