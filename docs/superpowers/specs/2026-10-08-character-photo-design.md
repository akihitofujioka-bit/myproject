# キャラクター写真 設計書

作成 2026-10-08。壱師アプリと件の統合（案A）を2つに分けたうちの **計画 1**。
計画 2（件の機能の移植）は別の設計書で扱う。

## 目的

新しいキャラクターの写真を、壱師アプリのトップ画面と各機能の画面に表示する。写真は機能ごとに登録でき、選んだ間隔で自動的に替わる。

## 決まったこと（利用者との確認 2026-10-08）

- 写真は **機能ごとに別** に登録する（トップ、冷蔵庫、書類、備蓄、家計簿、ポイントカードの 6 枠）
- 各機能の画面では、写真を **いちばん後ろの背景** にし、その前にボタンや一覧を置く
- トップ画面は、背景に **トップ用の写真**、各機能のアイコンに **その機能の写真** を出す
- 切り替えは **間隔を選んで自動**（毎日／毎週／毎月）
- **iPhone のホーム画面のアイコンは今のまま**。Apple Watch とウィジェットも変えない
- 写真は端末の中だけに保存し、外部へ送らない

## 1. 写真の登録と保存

### 登録画面

- トップ画面（`apps/index.html`）の設定欄（今「撮り方」を選んでいる所）に、「キャラクター写真」の欄を足す
- 6 枠それぞれでできること:
  - 写真を追加する。`<input type="file" accept="image/*" multiple>` を使い、写真アプリから選ぶ。何枚でも追加できる
  - 並べ替える（上へ／下へのボタン）
  - 削除する（確認の画面を出してから消す）
  - 切り替え間隔を選ぶ: 毎日／毎週／毎月（最初は「毎日」）
  - 膜の濃さを選ぶ: 薄い／普通／濃い（最初は「普通」）

### 保存

- IndexedDB のデータベース `character`（版 1）に、オブジェクトストア `slots` を作る。キーは枠の名前
- 枠の名前: `top`・`fridge`・`docs-tracker`・`stock`・`kakeibo`・`cards`
- 1 枠の中身:
  ```js
  {
    slot: "fridge",
    interval: "day",       // "day" | "week" | "month"
    veil: "normal",        // "light" | "normal" | "strong"
    photos: [Blob, ...]    // 登録順
  }
  ```
- 写真は保存する前に、長い辺が 1080 ピクセルを超えないよう縮め、JPEG（品質 0.85）にする。縮めるのは `<canvas>` で行う
- 読み込みに失敗したとき（IndexedDB が使えないなど）は、写真が無いときと同じ表示にする。画面は止めない

## 2. 表示と切り替え

### 共通の部品 `apps/shared/character.js`

`apps/shared/camerapref.js` と同じ書き方にする（即時関数で `global.Character` に公開し、`<script>` で読み込む）。公開する関数は次のとおり。

| 関数 | 役割 |
|---|---|
| `pickIndex(count, interval, date)` | 今日出す写真の番号を返す。写真が 0 枚なら `-1` |
| `veilAlpha(veil)` | 膜の濃さを不透明度に変える。`light`=0.55、`normal`=0.7、`strong`=0.85 |
| `load(slot)` / `save(record)` | 1 枠の読み書き |
| `currentPhotoURL(slot)` | 今日の写真の object URL を返す（無ければ `null`） |
| `applyBackground(slot)` | その画面の背景に写真と膜を付ける |
| `resize(file)` | 選んだ写真を縮めて Blob にする |

### 今日出す写真の決め方（`pickIndex`）

時計だけで決め、保存しておく情報はいらない。日付は端末の地域の時刻で数える。

- 基準日: 2026-01-05（月曜日）
- 毎日: 基準日からの日数
- 毎週: 基準日からの日数を 7 で割った整数（週の区切りは月曜日）
- 毎月: `(年 − 2026) × 12 + (月 − 1)`（月の区切りは 1 日）
- 上の数を写真の枚数で割った余りが、出す写真の番号になる。基準日より前の日付で数が負になっても、余りは 0 以上にする。写真が 1 枚なら、いつも 0 番

### トップ画面

- 背景に `top` 枠の写真と膜を出す
- 各機能のアイコン（`apps/index.html` の `<img src="fridge/icon-192.png">` など）を、その機能の写真に差し替える。アイコンの枠の形は今のまま（写真は枠に合わせて切り取って表示する）
- 写真が無い機能は、今のアイコン画像のまま

### 各機能の画面

- `fridge`・`docs-tracker`・`stock`・`kakeibo`・`cards` の各 `index.html` で `character.js` を読み込み、`Character.applyBackground("<枠の名前>")` を呼ぶ
- 背景は画面に固定する（一覧をスクロールしても動かない）。写真は画面いっぱいに広げ、はみ出た部分は切り取る
- 写真の上に、白い半透明の膜を重ねる（濃さは `veilAlpha` の値）
- カードやボタンは、今と同じ白い地のままにする（透けさせない）
- 写真が無いときは、今の背景色のまま

## 3. テスト

- `apps/tests/character.test.mjs`（ブラウザ不要。`node apps/tests/character.test.mjs` で動かす）で確かめる内容:
  - `pickIndex`: 毎日・毎週・毎月の切り替わり、週の区切り（日曜日→月曜日）、月の区切り（月末→1 日）、年またぎ、写真 1 枚、写真 0 枚
  - `veilAlpha`: 3 段階の値と、知らない値のとき `normal` の値になること
- 既存のテスト（`node apps/tests/*.test.mjs`）と Playwright の `smoke.mjs` が通ること
- iPhone に入れて実物で確かめる: 写真の登録、トップ画面の背景とアイコン、各機能の背景、文字の読みやすさ

## やらないこと

- 件の機能の移植は、この計画では扱わない（計画 2）
