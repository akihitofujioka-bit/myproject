# 名刺アプリと台形補正の入れ替え 設計書（計画 2-5）

作成 2026-10-15。壱師アプリと件 V2 の統合（案A＝件の機能を壱師へ移す）の計画 2-5。
2-3 で「対象外」とした名刺・連絡先の読み取りを、利用者の希望で取り込む。あわせて、無音カメラの台形補正を件の方式に寄せる。

## 目的

1. 名刺を撮って（または写真から）読み取り、壱師の中に名刺として残す
2. 名刺を「会った予定」と結び付け、「この会議で会った人」をたどれるようにする
3. 無音カメラの台形補正（紙の四隅を探して傾き・ゆがみを直す）を、見落としにくくする

## 決まったこと（利用者との確認 2026-10-15）

- 名刺の保存先は **壱師の中だけ**。iPhone の連絡先には登録しない
- 置き場所は **新しい「名刺」アプリ**（`apps/meishi/`。`apps/cards/` はポイントカードが使っている）
- 残すのは **文字の項目＋補正後の名刺の写真**
- 作り方は **案 1**: 文字の取り出しは iPhone 側（Swift）、項目の振り分けは Web 側（JavaScript）の決まった規則。AI は使わない
- **「この会議で会った人」** を作る。結び付きは名刺の側だけに持ち、予定のデータの持ち方は変えない
- 台形補正は、すでに無音カメラにある `cropToPaper` を **件の方式（書類らしさで探す）→ 今の方式（四角形を探す）** の順に試す形にする
- 2-3・2-4 とまとめて実機で確かめる。PR は #77 → 名刺の順で main に入れる

## 前提

- 台形補正は手帳の読み取り（a2df815）で無音カメラに入っており、どの撮影でも働いている（`SilentCameraViewController.autoCrop` は既定で有効）。カメラ設定の説明文「自動の切り出しなし」は古い
- 今の `cropToPaper` は `VNDetectRectanglesRequest` で四角形を探し、画面の 3 割以上の大きさのものだけを採る。机と紙の色が近いときや、名刺のように小さな紙は見落とす
- 件は `VNDetectDocumentSegmentationRequest`（iOS 15 以降）で書類を探している（`~/ScheduleReaderApp/ScheduleReader/Utilities/DocumentCorrector.swift`）
- 電話・メール・URL の取り出しは 2-3 の `apps/shared/contacts.js` にある

## 画面

### 名刺アプリ（`apps/meishi/index.html`）

- ホームに「名刺」を足す。下の帯に「← ホーム」。キャラクター写真の機能の一覧にも「名刺」を足す
- **一覧**: 新しく登録した順。氏名・会社・役職を表示。上の検索欄で、氏名・会社・部署・役職・メモ・会った予定の名前を探せる（ふりがなは持たない）
- **登録**: 「📷 撮る」または「🖼 写真から」→ 確認画面 →「保存」
- **確認画面**: 上に補正後の写真。下に入力欄（氏名・会社・部署・役職・電話（複数）・メール・住所・URL・もらった日（既定は今日）・会った予定・メモ）。読み取れなかった項目は空欄。保存は必ず人が押す
- **詳細**: 写真と項目。電話は `tel:`、メールは `mailto:` で開く。住所は表示だけ（地図を開くと外部のサービスに渡るため）。会った予定を押すと予定アプリのその予定を開く。「編集」「削除」（削除は確認つき）

### 会った予定の選び方

- 確認画面・編集画面の「会った予定」は、**もらった日** の予定を候補に並べ、1 つ選ぶ（選ばなくてもよい）
- 候補は、壱師の予定（`schedule.v1`）と iPhone のカレンダーの予定（予定アプリと同じ `CalendarReader` で読む）。壱師の予定とカレンダーの予定が calEventId で結び付いているものは 1 つにまとめる
- もらった日を変えたら候補を読み直す。選んでいた予定がその日に無ければ、選択を外す

### 予定アプリ（`apps/schedule/index.html`）

- 予定の詳細に「この会議で会った人」を出す。結び付いた名刺の氏名・会社を並べ、押すと名刺アプリのその名刺を開く。結び付いた名刺が無ければ欄ごと出さない
- 名刺の保存場所が開けないときは、欄を出さない（予定の表示は止めない）
- アプリ間の行き来は URL の `?id=` で行う。予定アプリにはまだこの仕組みが無いので、書類トラッカー（`apps/docs-tracker/index.html` の `URLSearchParams(location.search).get("id")`）と同じ形で足す。名刺アプリも `?id=` で名刺の詳細を開く。カレンダーだけにある予定（壱師の予定と結び付いていないもの）は開く先が無いので、名刺の詳細では文字の表示だけにする

### カメラ設定（`apps/shared/camerapref.js`）

- 無音カメラの説明を「音は鳴らない／ゆがみを自動で直す」に直す

## データ

- 保存場所: 端末内の IndexedDB `meishi`（オブジェクトストア `cards`、キーは `id`）。外部へは送らない
- 1 件の形:

```js
{
  id: "m-…",                 // 作るときに決める
  name: "", company: "", department: "", title: "",
  phones: [""],              // 電話・携帯（FAX は入れない）
  email: "", address: "", url: "",
  receivedOn: "YYYY-MM-DD",  // もらった日
  memo: "",                  // FAX や振り分けられなかった行もここへ
  meeting: null | {          // 会った予定
    scheduleId: "",          // 壱師の予定の id（無ければ ""）
    calEventId: "",          // カレンダーの予定の id（無ければ ""）
    title: "", date: "YYYY-MM-DD"  // 予定が消えても表示できるよう写して持つ
  },
  photo: Blob,               // 補正後の JPEG（短い辺 800px ほど、1 枚 50〜100KB）
  createdAt: "ISO 日時", updatedAt: "ISO 日時"
}
```

- 裏面・同じ人の 2 枚目の名刺は扱わない（別の 1 件として登録する）
- 予定を消しても名刺は消さない。予定アプリが「会った人」を探すときは、`scheduleId` か `calEventId` が一致する名刺を拾う
- 保存・一覧・検索・削除の部品は `apps/shared/meishistore.js` に分け、名刺アプリと予定アプリの両方から使う

## iPhone 側（Swift）

### 撮影（`ReceiptScannerPlugin.scan`）

- 撮る対象に `purpose: "card"` を足す。案内文は「名刺を枠いっぱいに写してください」。小さい文字も拾う設定（`minimumTextHeight` を手帳と同じ 0.006）にする
- `purpose: "card"` のときは、文字の行に加えて **補正後の写真** を返す（`photo`: JPEG を Base64 にした文字列、短い辺 800px、品質 0.7）
- 書類カメラ（VisionKit）を選んでいるときも同じく 1 枚目の写真を返す

### 写真から（`DocumentReaderPlugin.pickImage`）

- 引数 `withPhoto: true` のとき、台形補正をかけてから文字を読み、補正後の写真も返す（返す形は撮影と同じ）
- 引数が無いときの動き（2-4 の手書きメモ）は変えない

### 台形補正（`SilentCameraViewController.cropToPaper`）

- 順に試す
  1. `VNDetectDocumentSegmentationRequest`（件の方式）。見つかった四隅の面積が画面の 5% 以上なら採る
  2. 見つからなければ、今の `VNDetectRectanglesRequest`（3 割以上）
  3. どちらも無ければ、撮ったままの画像
- 四隅を少し外側に広げてから切り出す今の工夫（`margin 0.06`）は、両方の方式で使う
- 補正の部分は写真から読むときにも使うため、`DocumentCorrector`（新しいファイル `DocumentCorrector.swift`）に切り出す。`cropToPaper` はこれを呼ぶ

## 項目の振り分け（`apps/shared/meishi.js`）

入力は文字の行（文字・位置・高さ）。出力は上のデータの形の項目（写真・日付を除く）。AI は使わない。順に当てていき、当てた行は次から外す。

1. **電話・FAX・メール・URL**: `contacts.js` で取り出す。「FAX」「Fax」「F.」を含む行の番号は電話から外し、メモに「FAX: 番号」を入れる。「TEL」「携帯」「Mobile」の行はそのまま電話へ
2. **住所**: 「〒」や郵便番号（`\d{3}-\d{4}`）を含む行と、都道府県名で始まる行。住所の行のすぐ下の行が番地・建物名（数字か「ビル」「階」「F」を含む）なら続けてつなぐ
3. **会社**: 「株式会社」「(株)」「㈱」「有限会社」「合同会社」「市役所」「町役場」「村役場」「県庁」「議会」「協会」「組合」「法人」「事務所」「大学」「学校」を含む行
4. **部署**: 「部」「課」「係」「室」「局」「センター」「委員会」「グループ」で終わる語を含む行
5. **役職**: 「代表取締役」「取締役」「社長」「部長」「課長」「係長」「主任」「主査」「主事」「参事」「室長」「所長」「局長」「議長」「副議長」「議員」「委員長」「理事」「会長」「教授」を含む行。同じ行の残りが氏名らしければ（下の 6 の条件）氏名に回す
6. **氏名**: 残りの行のうち **文字の高さがいちばん大きい行** で、空白を除いて 2〜10 文字の漢字・かなのもの。姓と名の間の空白は 1 つにそろえて残す
7. 残った行はメモに改行でつなぐ

- 言葉の一覧はファイルの先頭に 1 か所でまとめる
- どの規則も、当たらなければ空欄。確認画面で人が埋める

## エラーのとき

| 起きたこと | 表示・動き |
|---|---|
| 撮影を閉じた | 何もしない |
| 文字が 1 行も読めない | 確認画面を空欄で開き「文字を読み取れませんでした。手で入力できます」 |
| 写真を縮められない | 写真なしで確認画面を開く |
| 保存できない | 「名刺を保存できません」。確認画面は閉じない |
| カレンダーを読めない | 会った予定の候補は壱師の予定だけにする |

## 確認の仕方

- **規則のテスト** `apps/tests/meishi.test.mjs`: 架空の名刺 10 種類ほど（役所・会社・議員・FAX あり・携帯あり・英字混じり・住所 2 行・役職と氏名が同じ行・会社名なし）の行データで各項目を確かめる
- **保存のテスト** `apps/tests/meishistore.test.mjs`: 保存・一覧・検索・削除・予定での検索
- **画面のテスト**（Playwright）: 見本の撮影結果で登録・一覧・検索・編集・削除・会った予定の候補（日付の変更を含む）・予定の詳細の「会った人」
- **iPhone のビルド**（`xcodebuild`）と、架空の名刺の画像（斜めに写したもの・机と色が近いもの）での台形補正と読み取り
- **実機での確認**: 2-3・2-4 の未確認項目とまとめて 1 枚の確認表にする
- 見本の名前・会社・番号はすべて架空のもの。本物の名刺は使わない

## この計画で扱わないこと

- iPhone の連絡先への登録・ほかのアプリへの共有
- 名刺の裏面、同じ人の名刺の更新
- 英語だけの名刺の項目の振り分け（文字は読む）
- ふりがな・読みでの検索
- 予定から名刺を結び付ける操作（結び付けは名刺の側からだけ）
- AI 秘書との結び付け、Apple Watch への表示
