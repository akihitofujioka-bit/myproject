# 名刺アプリと台形補正の入れ替え 実装計画（計画 2-5）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 名刺を撮って（写真から）読み取り、壱師の新しい「名刺」アプリに写真つきで残し、会った予定と結び付ける。無音カメラの台形補正を見落としにくくする。

**Architecture:** 文字と写真の取り出しは iPhone 側（Swift の既存プラグインに引数を足す）、項目の振り分けと会った予定の候補は Web 側の決まった規則（`apps/shared/meishi.js`）、保存は端末内の IndexedDB（`apps/shared/meishistore.js`）。予定アプリは名刺の保存場所を読むだけで、予定のデータの形は変えない。

**Tech Stack:** 素の JavaScript（ES5 の IIFE、`global.X = {...}` で公開）、IndexedDB、Capacitor 8、Swift（Vision・Core Image・PhotosUI）、Node のテスト（`node apps/tests/*.test.mjs`）、Playwright（画面テスト）。

**Spec:** `docs/superpowers/specs/2026-10-15-meishi-design.md`

## Global Constraints

- 外部へデータを送らない。名刺の住所から地図を開かない（表示だけ）
- 保存先は IndexedDB `meishi`、オブジェクトストア `cards`、キー `id`。`schedule.v1` の形は変えない
- 写真は補正後の JPEG、短い辺 800px、品質 0.7。JS へは Base64 で渡し、保存は Blob
- 項目の振り分けに AI を使わない。当たらない項目は空欄
- テスト・見本の名前・会社・番号・住所はすべて架空。本物の名刺は使わない
- 画面の文言・コメントは日本語。既存ファイルの書き方（ES5・IIFE・2 スペース）に合わせる
- Codex に頼む作業: 個人情報フォルダを読まない、ネットに接続しない、`git commit`・`git push` をしない（スキル `build-app`）
- 予定アプリには「詳細」画面は無く、予定を押すと編集フォーム（`startEditing(item)`、`apps/schedule/index.html:1720`）が開く。設計書の「予定の詳細」はこのフォームを指す

## Review Focus

1. **文字が 1 行も読めない名刺**（真っ白な写真・ロゴだけ）→ 確認画面が空欄で開き「文字を読み取れませんでした。手で入力できます」。Task 1 と Task 3 にテストを入れる
2. **FAX と電話が同じ行・FAX の行に番号が 2 つ**（`TEL 03-1234-5678 FAX 03-1234-5679`）→ FAX の番号だけメモへ、TEL の番号は電話へ。Task 1
3. **会った予定が後で消えた／`?id=` の予定や名刺が無い** → 名刺の詳細は写した予定名と日付を文字で表示。存在しない id で開いたら一覧のまま「見つかりませんでした」。Task 3・Task 4
4. **縦書き風・行がばらばらの名刺**（高さが同じ行ばかり、位置の情報が無い文字列だけの行）→ 落ちずに、氏名は条件に合う最初の行。Task 1
5. **名刺の保存場所が開けない**（IndexedDB が使えない）→ 予定アプリの表示・編集は止まらず「会った人」の欄が出ないだけ。Task 4
