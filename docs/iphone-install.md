# 「ふたりのメッセージ」を自分の iPhone に入れる

方法は2通りある。**Mac があるかどうか**で決まる。

| | A. ホーム画面に追加 | B. アプリとして入れる |
| --- | --- | --- |
| Mac | **不要** | **必要**（Xcode を使う） |
| 費用 | 0円 | 0円（7日ごとに入れ直し）／年約15,000円で1年間有効 |
| 手間 | 1分 | 初回1〜2時間（Xcode の導入を含む） |
| 見た目 | アイコンから起動。ほぼアプリと同じ | 完全にアプリ |
| 写真の添付 | できる | できる |
| **着信の通知** | アプリを開いている間だけ | **閉じていても届く** |
| データの守り | ブラウザの保存領域 | **iCloud バックアップから除外済み** |

**まず A で試すことを勧める。** 使ってみて「通知が来ないと困る」と感じたら B に進めばよい。
どちらでも、**中継サーバーが `https://` で動いていること**が前提（[messenger-setup.md](messenger-setup.md)）。

---

## A. ホーム画面に追加する（Mac 不要・1分）

1. **Safari で**アプリのページを開く（GitHub Pages で公開した URL の `messenger/`）
   - Chrome ではなく Safari で開くこと。ホーム画面への追加は Safari だけの機能
2. 画面下の**共有ボタン**（□に↑）を押す
3. 一覧を下にたどって「**ホーム画面に追加**」を選ぶ
4. 名前を確認して「追加」

ホーム画面にアイコンができ、タップすると全画面で起動する。

### この方法の注意点

- **通知は届かない。** アプリを開いたときに、その間に届いたメッセージがまとめて表示される
- **保存領域が消える場合がある。** 端末の空き容量が足りなくなったときなど、
  iOS がアプリの保存領域を整理することがある。そうなると**鍵も履歴も失われ、元に戻せない**
  → 大事なやりとりをしているなら、ときどき設定の「**JSONで保存**」で控えを取ること
- Safari の「履歴とWebサイトデータを消去」を実行しても消える

## B. アプリとして入れる（Mac が必要）

### 用意するもの

- Mac（Apple Silicon でも Intel でもよい）
- Xcode（Mac App Store から無料。初回は 10GB 以上のダウンロードがある）
- Node.js 18 以降
- Apple ID（無料のもので可）
- iPhone と、それをつなぐケーブル

### 手順

```bash
git clone https://github.com/akihitofujioka-bit/myproject.git
cd myproject/mobile-messenger
npm install
npm run ios        # www を作り直して Xcode を開く
```

Xcode が開いたら：

1. 左の一覧から **App** を選び、**Signing & Capabilities** タブを開く
2. **Team** に自分の Apple ID を選ぶ（初回は「Add an Account…」から登録する）
3. **Bundle Identifier** が他人と重複しているとエラーになる。
   その場合は `jp.myproject.messenger` の後ろに何か足す（例：`jp.myproject.messenger.taro`）
4. iPhone を Mac につなぎ、画面上部の実行先を自分の iPhone にする
5. **▶︎（Run）**を押す

### iPhone 側で許可する

初回は「信頼されていない開発元」と出るので、
**設定 → 一般 → VPNとデバイス管理** から自分の Apple ID を選び「信頼」する。

### 費用と有効期限

- **無料の Apple ID**：アプリは**7日間**で起動できなくなる。Mac につないで再度 ▶︎ を押せば復活し、
  **会話の履歴はそのまま残る**（アプリを消さない限り）
- **Apple Developer Program（年 約15,000円）**：1年間有効になる

### 更新するとき

`apps/messenger/` を直したあと、Mac で次を実行して Xcode から再ビルドする。

```bash
cd mobile-messenger
npm run ios
```

## このアプリの iPhone 側の作り込み

| 項目 | 設定 | 理由 |
| --- | --- | --- |
| iCloud・パソコンへのバックアップ | **対象外** | 秘密鍵と会話の履歴を端末の外へ出さないため |
| アプリ切り替えの一覧 | **会話が写らない** | 一覧の画像から内容が読まれないようにするため |
| 暗号化なしの通信 | **禁止** | `http://` を一切使わせない |
| 写真・カメラの利用目的 | **日本語で明記** | これが無いと写真を選ぶ瞬間にアプリが落ちる |

> **バックアップ対象外にしていることの意味。**
> **機種変更しても、メッセージは新しい iPhone に引き継がれません。**
> 引き継ぐときは、必ず先にアプリの設定から「JSONで保存」を行ってください。
> この動きを変えたい場合は、`ios/App/App/AppDelegate.swift` の
> `excludeAppDataFromBackup()` の呼び出しを消してビルドし直します。

### スクリーンショットについて（Android との違い）

**iOS には、スクリーンショットを止める仕組みがありません。**
Android 版（相手に渡す版）では撮影と録画を禁止していますが、iPhone 側では**あなたは撮影できます**。

つまり「消えるメッセージ」に関して、**相手は撮れないが自分は撮れる**という非対称があります。
相手にこの点を伝えておくのが誠実です。

## 困ったとき

| 症状 | 確かめること |
| --- | --- |
| Xcode で `Signing for "App" requires a development team` | 手順2の Team を設定していない |
| `Unable to install` と出る | Bundle Identifier が他人と重複している。手順3のとおり変える |
| 起動してすぐ落ちる | Info.plist の写真・カメラの利用目的が消えていないか（既定では入っている） |
| 「未接続」のまま | 中継サーバーが動いているか、`https://` になっているか |
| 7日たって起動しなくなった | 無料 Apple ID の期限。Mac につないで ▶︎ を押し直す（履歴は残る） |

---

## この環境で確認できていないこと

**Xcode でのビルドは未検証。** この開発環境には macOS も Xcode も無いため。

確認済みなのは次のところまで。

- iOS プロジェクトの設定（利用目的の文言・通信・バックアップ除外・アイコン・起動画面）が意図どおりであること
- **アプリに入るのと同じ `www/` の中身**が、ブラウザ上で実際に動くこと

検査は `node apps/tests/mobile-package.test.mjs` で行っている。
