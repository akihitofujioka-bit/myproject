# 議会だより原稿編集ツール

議会だより（議会広報紙）の原稿を取り込み、決まった誌面構成にそって順番に編集していくためのツールです。

- 実体: `gikai-dayori/index.html`（単一HTMLファイル）
- 使い方: ファイルをブラウザで開くだけ。サーバー不要、インターネット接続不要、外部への送信なし。
- 保存先: 入力内容はブラウザの `localStorage` に自動保存されます（**そのPC・そのブラウザの中だけ**）。

---

## 1. 誌面構成（編集する順番）

議会だよりの構成に合わせて、次の7ページを**この順番**で編集します。

| # | ページ | 内容 | 備考 |
|---|---|---|---|
| 1 | 表紙 | 号数・発行日・表紙写真のキャプション・今号の主な内容（目次） | |
| 2 | 行政報告 | 町長（市長）の行政報告の要旨 | |
| 3 | 審議したこと・決まったこと | 議案の審議結果（可決・否決・同意など）、賛否の状況 | |
| 4 | 閉会中の委員会活動報告 | 各常任委員会・特別委員会・議会運営委員会の活動 | 「委員長」欄あり |
| 5 | 一般質問 | 議員ごとの質問と答弁 | 「議員名」欄あり |
| 6 | 特集 | 今号に特集がある場合のみ | **任意**（スイッチでオフにできる） |
| 7 | 最終ページ（編集後記＋α） | 編集後記、お知らせ、今後の日程、傍聴案内など | |

特集をオフにすると、そのページは編集対象から外れ、「次のページ →」でも自動的にスキップされ、書き出し結果にも含まれません。

---

## 2. 画面の構成

上部のタブで3つの画面を切り替えます。

### ① 原稿ボックス

取り込んだ原稿を溜めておく場所です。ここから各ページへ割り当てて使います。

**取り込み方法**

- テキストファイル（`.txt` / `.md` / `.csv`）をドラッグ＆ドロップ、または「ファイルを選択」
- 下の欄に本文を貼り付けて「原稿ボックスに追加」

**分割方法**（複数の原稿をまとめて貼るとき）

| 設定 | 動作 |
|---|---|
| 分割しない | 全体を1件として取り込む |
| 区切り線（`---`）で分割 | `---` の行ごとに分ける |
| 見出し（`#`）で分割 | `#` で始まる行ごとに分ける |
| 空行2行で分割 | 空行が2行以上続く箇所で分ける |

原稿名は本文の先頭行（`#` は自動で除去）から自動で付きます。

### ② 誌面編集

上部のステッパー（1〜7）で現在位置がわかります。クリックで直接移動、下部の「← 前のページ / 次のページ →」で順番に移動します。

各ページでできること:

- **原稿ボックスから挿入** — 取り込み済みの原稿を選んで（複数可）記事として差し込む。先頭が `#` 見出しなら見出しが「タイトル」、残りが「本文」に入り、その原稿は自動でこのページに割り当て済みになります。
- **＋ ○○を追加** — 空の記事を追加
- 記事ごとに「タイトル / 担当（議員名・委員長）/ 本文 / 目標字数 / メモ」を入力
- `↑` `↓` で記事の並べ替え、「削除」で記事を削除（確認あり）
- **目標字数** を入れると、超過は赤、9割以上は橙で残り字数を表示（字数は改行・空白を除いた実質字数）
- 「このページの編集を完了にする」でチェック → ステッパーに ✓、進捗バーとタブのバッジ（例 `3/6`）に反映
- ページ全体のメモ欄（書き出しには含まれません）

### ③ プレビュー・書き出し

- 全体を Markdown で組み上げてプレビュー
- 「Markdownをコピー」「Markdownをダウンロード」「テキストをダウンロード」「印刷 / PDF」
- 集計（使用ページ数・編集完了・記事数・総文字数・未割り当ての原稿数）

## 3. 原稿の選択と一括削除

「取り込んだ原稿」の一覧で、行の左端のチェックボックスで原稿を選びます。

- **表示中をすべて選択** — 検索・フィルタで絞り込んだ結果だけをまとめて選択
- 選択件数はツールバーに表示されます
- **選択した原稿を一括削除** — 確認ダイアログに「削除件数」と「対象の原稿名一覧」が出て、割り当て済みの件数も警告されます。「削除する」を押すまで消えません
- **選択した原稿を割り当て…** — 選択した原稿をまとめて指定ページへ割り当て
- **割り当てを解除** — 選択した原稿の割り当てを外す
- 検索欄（原稿名・本文を対象）、フィルタ（すべて / 未割り当てのみ / ページ別）で絞り込めます

> 原稿ボックスから原稿を削除しても、**すでに誌面へ挿入した本文は消えません**（挿入時にコピーされるため）。誌面側の記事は各記事の「削除」ボタンで消します。

## 4. データの保存・持ち出し

| 操作 | 内容 |
|---|---|
| 自動保存 | 入力のたびにブラウザへ自動保存。ヘッダー右に保存時刻を表示 |
| バックアップ保存 | 全データを JSON ファイルとして書き出し |
| バックアップ復元 | JSON を読み込んで復元（現在の内容は破棄。確認あり） |
| 全消去 | まっさらな状態に戻す（確認あり） |

**注意点**

- データはブラウザに保存されるため、別のPC・別のブラウザ・シークレットウィンドウには引き継がれません。共有・引き継ぎには「バックアップ保存」の JSON を使ってください。
- ブラウザの「閲覧データの削除（Cookieとサイトデータ）」を実行すると消えます。作業の区切りごとにバックアップを取ることを推奨します。

---

## 5. 想定する使い方の流れ

1. ヘッダーに号数と発行日を入力
2. 各担当から集まった原稿ファイルを「原稿ボックス」へまとめて取り込む
3. 不要な原稿・重複した原稿にチェックを入れて**一括削除**、必要な原稿はページごとに一括割り当て
4. 「誌面編集」で表紙から順番に、原稿を差し込み・見出しと本文を整える
5. ページごとに目標字数を入れて字数調整、終わったら「完了」にチェック
6. 全ページ完了したら「プレビュー・書き出し」から Markdown / テキストを書き出して、レイアウト担当や印刷所へ渡す

---

## 6. 仕様メモ

- 依存ライブラリなし（素の HTML / CSS / JavaScript のみ）
- `localStorage` キー: `gikai-dayori-editor-v1`
- 保存データにセクション定義の増減があっても、読み込み時に現在の構成へ合わせ直します（既存の入力は id が一致するページに引き継がれます）
- 文字数カウントは改行・半角スペース・タブを除いた文字数
