# 読み上げリーダー（Yomiage）

PDF・EPUB・テキストを取り込んで、iPhone の合成音声で読み上げる iOS アプリです。
本文の解析も音声合成もすべて端末内で完結し、ファイルを外部サーバーへ送信することはありません。

## できること

- **本の取り込み** — `＋` ボタン、または「ファイル」アプリの共有メニューから取り込み（PDF / EPUB / .txt / .md）
- **文単位の読み上げ** — 読み上げ中の文をハイライトし、自動でスクロール
- **頭出し** — 文をタップでその場から再生、スライダーで任意の位置へジャンプ、見出し単位の章送り
- **しおり** — 読み上げ位置を自動保存し、次に開いたときは続きから
- **バックグラウンド再生** — 画面を消しても継続。ロック画面・コントロールセンターから再生／停止／文送り
- **声と速度の設定** — 端末にインストール済みの音声から選択、速度 ×0.5〜×2.0、声の高さの調整
- **おやすみタイマー** — 5〜60 分後に自動停止

## ビルド方法

Mac と Xcode 16 以降が必要です。

1. `ios/Yomiage.xcodeproj` を Xcode で開く
2. ターゲット `Yomiage` の *Signing & Capabilities* で、自分の Apple ID（チーム）を選ぶ
3. `PRODUCT_BUNDLE_IDENTIFIER` を自分用の値に変更する（初期値は `com.example.yomiage`）
4. 実機を選んで Run

無料の Apple ID でも実機インストールは可能ですが、その場合はビルドしたアプリの有効期限が 7 日間で、期限が切れるたびに再インストールが必要です。

- 最小 iOS バージョン: 17.0
- 外部ライブラリ: なし（PDFKit / AVFoundation / NaturalLanguage など OS 標準のみ）

## 音声の品質を上げる

初期状態の日本語音声は「標準」品質です。iPhone の
**設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語** から高品質音声
（拡張／プレミアム）をダウンロードすると、アプリの読み上げ設定に自動で現れます。

## 構成

```
ios/
├── Info.plist                  バックグラウンド再生・書類種別の宣言
├── Yomiage.xcodeproj/
└── Sources/
    ├── App/YomiageApp.swift    エントリポイント
    ├── Models/                 Book（本棚の 1 冊）、BookDocument（分割済み本文）
    ├── Library/                取り込み・保存・本棚画面
    ├── Parsing/                PDF / EPUB / テキストの本文抽出と文分割
    │   ├── PDFTextExtractor    PDFKit でページ単位に抽出し、折り返し行を段落へ復元
    │   ├── EPUBParser          ZIP → container.xml → OPF → XHTML の順にたどる
    │   ├── ZIPArchive          EPUB を開くための最小限の ZIP リーダー
    │   ├── HTMLTextExtractor   XHTML から本文だけを取り出す（ルビの rt は除外）
    │   └── TextSegmenter       NaturalLanguage で文へ分割し、長文はさらに区切る
    ├── Speech/                 AVSpeechSynthesizer の制御、音声一覧
    └── Reader/                 読み上げ画面・再生バー・設定シート
```

## 制限事項

- **スキャン画像だけの PDF は読み上げできません。** 文字情報を含まないため、取り込み時に
  その旨のエラーを表示します。OCR で文字を埋め込んだ PDF を使ってください。
- **DRM 付き EPUB は開けません。** 暗号化されていない EPUB（EPUB 2 / 3）のみ対応です。
- ZIP64 形式で圧縮された EPUB には未対応です。
- PDF は段組みや図表の配置によって、読み上げ順が意図と異なる場合があります。
- 音声は iOS 内蔵の合成音声です。クラウド TTS のような自然さはありません。
