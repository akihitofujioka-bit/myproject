# 議会だより 原稿編集ツール

各議員からばらばらの様式で届く原稿を、**校正・要約し、写真を配置して、
Word の様式に流し込む**までを支援するツールです。

**インターネットにつながずに動きます。** 原稿・写真・議員名などの情報が
外部に送信されることは一切ありません。通信するのはこのパソコンの中
（127.0.0.1）だけです。

---

## 使い方はツールの中にもあります

**画面右上の「使い方」ボタン**から、いつでも読めます。
各手順の見出しにある **?** を押すと、その手順の説明だけが開きます。
**「印刷する」で紙に出せる**ので、パソコンの横に置いておけます。

このファイルは、導入や自治体ごとの調整まで含めた詳しい版です。

---

## 2つの使い方

画面の上で切り替えられます。

### かんたん作成（おすすめ・既定）

**覚えることは3つだけです。**

1. **最大ページ数を決める**
2. **区分ごとのフォルダに、原稿と写真を入れる**
3. **「議会だよりを作る」を1回押す** → できあがりを見て、書き出す

区分の振り分けも、写真の割り付けも、ページ数の調整も自動です。
**どのフォルダに入れたかが、そのまま紙面の場所になります。**

### くわしく編集

1本ずつ校正しながら仕上げたいときは、こちらに切り替えます。
下の①〜⑥の手順が使えます。かんたん作成で作ったあとに切り替えて、
気になるところだけ直す、という使い方もできます。

---

## できること

| 手順 | やること | ツールがやってくれること |
|---|---|---|
| ① | 号を作る | 1号ぶんの作業をフォルダ1つにまとめて保存 |
| ② | 原稿を集める | Word（**旧形式 `.doc` も**）・テキスト・PDF・リッチテキストを様式を問わず取り込み、文字コードも自動判別 |
| ③ | 校正・要約 | 誤字脱字・表記ゆれ・固有名詞の誤記を指摘。枠の字数に合わせて要約 |
| ④ | 写真 | 向きの補正、枠の縦横比に合わせた切り出し、印刷解像度の判定。**原稿と同じ名前にしておけば、その記事のページへ自動で配置** |
| ⑤ | 紙面に組む | **1ページ5段・縦書きを保ったまま、分量に応じてページ数を自動調節**（自動組版）。前号の様式に差し込む方式も選べます |
| ⑥ | 書き出し | 差し込み済みの Word（必要なら PDF）を出力 |

## 使いはじめる

### 必要なもの

- **Python 3.10 以降**（必須）
  Windows: <https://www.python.org/downloads/windows/>
  インストール時に **「Add Python to PATH」に必ずチェック**を入れてください。

- **Pillow**（推奨）— 写真の切り出し・向き補正・解像度チェックに使います
- **PyMuPDF**（推奨）— PDF で届いた原稿を読むときに使います
- **LibreOffice**（任意）— PDF の書き出しと、`.doc` の**様式**の変換に使います。
  Windows で Word が入っていれば不要です。<https://ja.libreoffice.org/download/>

Pillow・PyMuPDF は **`wheels` フォルダに同梱してあります。**
`追加部品のインストール.bat` をダブルクリックすれば、**インターネットに
つながっていないパソコンでも入ります**（同梱ファイルだけを見に行きます）。

同梱の対象は **Windows 64ビット版 / Python 3.10〜3.14** です。
macOS・Linux では同梱ファイルを使えないので、インターネット経由で入れてください:

```
pip install -r requirements.txt
```

`wheels` フォルダを新しくする方法は `wheels/README.txt` に書いてあります。

※ 何も入れなくても、`.docx`・テキスト原稿の取り込みと Word への差し込みは動きます。

### 起動と終了

#### はじめに一度だけ

Windows では `デスクトップにアイコンを作る.bat` をダブルクリックしてください。
デスクトップに専用アイコンのショートカットができます。以後はそれを
ダブルクリックするだけで起動できます。

> うまくいかない場合は、`起動.bat` を右クリック →「送る」→
> 「デスクトップ (ショートカットを作成)」でも作れます。できた
> ショートカットのプロパティから「アイコンの変更」で `icon.ico` を
> 選んでください。

#### 起動

- **Windows** — デスクトップのアイコン（または `起動.bat`）をダブルクリック
- **macOS / Linux** — `./start.sh`
- 手動 — `python app.py`

ブラウザが自動で開きます。開かないときは
`http://127.0.0.1:8730/` をブラウザに貼り付けてください。

**黒い画面は、起動が終わると自動で閉じます。** 本体は画面を出さずに
動き続けるので、そのまま使えます。

すでに起動しているときにもう一度アイコンを押しても、二重には
起動しません。ブラウザで画面が開くだけです。

#### 終了

**画面右上の「終了」ボタン**を押してください。黒い画面が出ていないため、
これが通常の終わり方になります。

うまく終われないときは `終了.bat` をダブルクリックしてください。
（コマンドで終わらせる場合は `python app.py --quit`）

> 終了せずにパソコンを終了しても、データは失われません。
> 編集内容は「保存」を押した時点でフォルダに書き込まれています。

#### Python が見つからないと言われたら

各バッチファイルは、`py` ランチャー → `python` → `python3` →
よくあるインストール先、の順に **実際に動かして確かめてから**使います。

ほかのソフトが入れた Python が PATH に残っていて壊れている場合
（`Unable to create process` と出るとき）も、その Python は自動的に
飛ばして次の候補を試します。それでも見つからない場合は、
Python 本体を入れ直してください。

### 保存先フォルダ

作業データは **デスクトップの「議会だより」フォルダ** に保存されます。
フォルダが無ければ起動時に自動で作られます。

デスクトップの場所は次のように調べるので、OneDrive にデスクトップが
移されている場合や、Mac・Linux でも正しい場所に作られます。

| OS | 調べ方 |
|---|---|
| Windows | レジストリの Shell Folders（OneDrive へのリダイレクトに対応） → `%USERPROFILE%\Desktop` |
| macOS | `~/Desktop` |
| Linux | `~/.config/user-dirs.dirs` の `XDG_DESKTOP_DIR` → `~/Desktop` → `~/デスクトップ` |

保存先を変えたいとき:

```
python app.py --workspace "D:\議会だより"
```

指定した場所に作れなかったとき（権限が無い、ドライブが無いなど）は、
ホームフォルダの下に切り替えて起動を続けます。切り替えたことは
起動時の黒い画面に表示されます。

## 進め方（かんたん作成）

### 1. 号とページ数を決める

号の名前（例: 第204号）を入れて「この号をはじめる」を押します。
続けて **最大ページ数** を入れて「この枚数にする」を押します。

既定は **22ページ**（日高村議会だよりの1号あたりの上限）です。

- **「ここまでに収める」という意味**です。ちょうど22ページにはそろえません
- 上限に入りきらないときだけ、**長い原稿を自動で要約**して収めます
- 何をどれだけ詰めたかは、作ったあとに一覧で出ます
- **0 にすると成り行き**（原稿の分量どおりにページが増えます）

#### ページ数は号によって変わってかまいません

**一般質問の人数が増えれば、そのぶんページも増えます。** そのままで
大丈夫です。段数（1ページ5段・縦書き）は固定したまま、
**中身の分量に合わせてページ数のほうが動きます。**

実測した例（原稿の分量によって変わります）:

| 一般質問 | ページ数 |
|---|---|
| 0人 | 3ページ |
| 4人 | 4ページ |
| 6人 | 5ページ |
| 10人 | 6ページ |

**詰めたくないときは**、画面に出る「1字も詰めずに組むと◯ページ」を
最大ページ数に入れ直して、もう一度作り直してください。

> 紙は表と裏があるので、**奇数ページだと最後の1ページが白紙**になります。
> 組み上がったときに奇数なら画面で知らせます
> （第203号は18ページ、上限は22ページ — どちらも偶数です）。

> ページ数は**組み上がった紙面を実際に数えています**（目安ではありません）。
> Word も LibreOffice も入っていないパソコンでは数えられないため、
> そのときは「目安です」と画面に出ます。

### 2. フォルダに原稿と写真を入れる

号を作ると、区分ごとのフォルダができます。

```
第204号/原稿/
  01_表紙/
  02_行政報告/
  03_審議したこと・決まったこと/
  04_閉会中の委員会活動報告/
  05_一般質問/
  06_特集/
  07_最終ページ/
  はじめにお読みください.txt      ← 置き方の説明が入っています
```

「原稿フォルダを開く」を押すとエクスプローラーで開きます。
**載せたい区分のフォルダへ、届いた原稿と写真をそのまま入れてください。**

| したいこと | やり方 |
|---|---|
| 載せる順番を決める | ファイル名の先頭に番号を付ける（`01_あいさつ.docx` → `02_森下けい子.docx`） |
| 写真を記事に付ける | 原稿と同じ名前にする（`森下けい子.docx` ↔ `森下けい子.jpg`） |
| 写真を複数付ける | `森下けい子1.jpg` `森下けい子2.jpg`（番号順に入ります） |
| 記事を取り下げる | フォルダからファイルを消して、作り直す |
| 名前を変える・区分を移す | 画面のファイル名を押す（下記） |
| 写真を原稿に結びつける | 「写真を原稿に割り当てる」で、写真を見ながら選ぶ（下記） |

入れ終わったら「入れ終わったので数え直す」を押すと、
どのフォルダに何件入っているかが画面に出ます。

> この7つの区分は、**どれも毎号あるもの**です（特集も毎号あります）。
> 原稿が入っていない区分があると、フォルダの一覧に色が付き、
> 作ったあとにも「原稿が入っていない区分があります」と出ます。
> 入れ忘れでなければ、そのまま進めて構いません。

#### 写真を原稿に割り当てる（名前がばらばらでも大丈夫）

届く写真は `IMG_2451.jpg` `DSC00123.jpg` のように、**原稿とはまったく違う
名前**で来ます。名前を1枚ずつ打ち直すのは大変なので、
**写真を見ながら「どの原稿のものか」を選ぶだけ**で済むようにしました。

「写真を原稿に割り当てる」を押すと、区分ごとに写真が並びます。

- **選ぶだけで名前がそろいます** — 1枚なら `01_森下けい子.jpg`、
  複数なら `01_森下けい子1.jpg` `01_森下けい子2.jpg`
- **すでに名前が合っているものは、初めから選んであります。**
  色が付いているもの（＝カメラの名前のままのもの）だけ選べば済みます
- **「この号では使わない」** を選ぶと、消さずに区分フォルダの下の
  `使わない写真` フォルダへよけます。あとから戻せます
- 取り違えて割り当ててしまっても、もう一度開いて選び直せば入れ替わります

#### 名前は画面から変えられます

原稿のほうも「原稿.docx」「森下.docx」のように名前がばらばらで届きます。
**エクスプローラーへ行かなくても、画面のファイル名を押せば変えられます。**

- **名前を変える** … 新しい名前を入れるだけ（種類 `.docx` などは変わりません）
- **別の区分へ移す** … 同じ画面の「入れる区分」で選び直します
- **写真もそろえる** … 原稿の名前を変えると、**その原稿に付いている写真の名前も
  一緒にそろえます**（既定で入っています）。そろえないと結びつきが外れます
- **番号を振り直す** … 区分ごとのボタン。いまの並びのまま `01_` `02_` … を
  付け直します。写真の番号も合わせて付け替えます

同じ名前がすでにある場合や、フォルダの外を指した場合は断ります。

> 名前を変えても、**取り込み済みの記事や写真との結びつきはそのまま**です。
> 作り直したときに「新しく入った」ではなく「そのまま」と出れば、
> ちゃんと引き継げています。

> 番号（`01_`）は並べるためのものなので、写真と突き合わせるときは外して見ます。
> `01_森下けい子.docx` と `森下けい子.jpg` でも、ちゃんと結びつきます。
> 名前の合わない写真は、その区分の**先頭の記事**に付きます（迷子にしません）。

### 3. ボタンひとつで作る

「議会だよりを作る」を押すだけです。1ページ5段の縦書きで、
表紙 → 行政報告 → … → 最終ページ の順に組み上がります。

押したあと、次のことが画面に出ます。

- **できあがりのページ数**（最大ページ数に収まったか）
- **紙面の並び**（区分ごとの本数と字数）
- **フォルダから取り込んだもの**（新しく入った／読み直した／そのまま／外した）
- **ページ数に合わせて詰めたところ**（記事ごとに何字→何字）
- 読めなかったファイルがあれば、その理由

**何度でも押せます。** フォルダの中身がそのまま紙面になるので、
同じフォルダからは必ず同じものができます。原稿を直したら、
また押せばそれが反映されます。

作り直すたびに、取り込んだままの原稿から組み直します。
**何度押しても本文がどんどん短くなることはありません。**
最大ページ数を増やせば、詰めた本文はもとに戻ります。

ページ数が奇数のときは、最後が白紙になることを画面で知らせます。

> ⚠ 「くわしく編集」で本文を直したあとに作り直すと、
> **フォルダの原稿から組み直すので、直した内容は元に戻ります。**
> そのときは押す前に確認の画面が出ます。直した内容を残したいときは、
> フォルダの原稿ファイル自体を直してください。

### 4. できあがりを見て、書き出す

「できあがりを見る」で、**刷り上がりと同じ形**を画面で確認できます
（Word か LibreOffice があれば PDF にして表示します。
どちらも無いパソコンでは「Word で開く」をお使いください）。

- **Word で開く** … 組み上がった Word をそのまま開きます
- **保存フォルダを開く** … 印刷所に渡すファイルの置き場所を開きます

書き出したファイルは `第204号/出力/` に入っています。

## 進め方（くわしく編集）

### ① 号を作る

「第204号」のように名前をつけて作成すると、保存先フォルダの下に
次の構成でフォルダができます。

```
第204号/
  project.json      記事・割付・設定（作業データ）
  template.docx     様式（Word）
  manuscripts/      議員から届いた原稿の原本
  photos/           写真の原本
  出力/             差し込み済みの Word / PDF
  user_dict.json    この号だけの固有名詞辞書
```

**このフォルダごとコピーすれば、別のパソコンに作業を引き継げます。**
共有フォルダに置いて交代で編集する運用もできます（同時編集はできません）。

### ② 原稿を集める

届いたファイルを画面にドラッグ＆ドロップするだけです。

- `.docx` — 本文・表・テキストボックスの中身まで拾います。埋め込み写真も取り込みます
- `.doc` — **旧形式もそのまま読めます**（追加ソフトは不要）。テキストボックスの中身も拾います
- `.txt` — Shift-JIS（CP932）・UTF-8・EUC-JP を自動判別します
- `.pdf` — PyMuPDF で読みます。無い場合は pypdf で読みますが、日本語 PDF では
  文字が乱れることがあります（スキャンした画像だけの PDF はどちらでも読めません）
- `.rtf` — 書式を捨てて文字だけ取り出します
- メール本文などは「直接貼り付ける」欄に貼れます

取り込むときに、次の整形を自動で行います（設定で切り替えられます）。

- 半角カナ → 全角
- 句読点・括弧を全角に統一
- 全角英数字 → 半角
- **数字を縦書きの慣行に合わせる**（1桁は全角「４月」、2桁以上は半角「12日」）

1行目が短く句点で終わっていない場合は、**見出しとみなして本文から切り出します**。
違っていた場合は、③の画面で「取り込んだ原稿に戻す」を押せば元に戻せます。

#### 紙面の区分（構成）の割り振り

取り込んだ原稿は、**議会だよりの構成のどこに載るか**が自動で振り分けられます。

| 区分 | 中身 |
|---|---|
| 表紙 | 題字・特集の予告・巻頭の記事 |
| 行政報告 | 村長からの報告（要旨） |
| 審議したこと・決まったこと | 議案・発議案と賛否、人事、その他 |
| 閉会中の委員会活動報告 | 常任委員会・特別委員会の報告 |
| 一般質問 | 議員ごとの質問と答弁 |
| 特集 | その号の企画（**毎号あります**） |
| 最終ページ | 編集後記、お知らせ、写真募集など |

判定は**ファイル名 → 見出し → 本文の書き出し**の順に見当を付けます。
`04_一般質問_森下けい子.docx` のような名前を付けておくと、まず外れません。

- 一覧の選択欄で**その場で選び直せます**（判定のもとは欄にカーソルを乗せると出ます）
- 判定できなかったものは「未分類」になり、③の一覧の最後にまとまります
- 「区分を自動で振り分ける」を押すと、まとめて付け直せます

#### 原稿をまとめて削除する

チェックを付けて「選択した原稿を削除」を押します。「すべて選択」でまとめて選べます。

削除しても、**取り込んだ元のファイル（`manuscripts` フォルダ）と写真は残ります**。
消したあとで取り込み直せます。ただし**この画面で直した本文や要約は元に戻せません**。
確認の画面に、消える原稿の一覧が出ますので確かめてください。

### ③ 校正・要約

左の一覧は、**紙面に載る順**（表紙 → 行政報告 → 審議したこと・決まったこと →
閉会中の委員会活動報告 → 一般質問 → 特集 → 最終ページ）に並んでいます。
**上から順に片付けていけば、1号ぶんが仕上がります。**

- 区分の見出しに「0/2 本・96 字」のように、**校正の済み具合と分量**が出ます
- 記事の右の **▲▼** で、同じ区分の中の**載る順番**を入れ替えられます
- 区分そのものを変えたいときは、編集画面の「紙面の区分」で選び直します
- 原稿が1本も無い区分もそのまま出します（**7つの区分はどれも毎号ある**ので、
  空のままなら入れ忘れの可能性があります）

⑤の自動組版は、**この並びのとおりに**紙面を組みます。
区分の変わり目には、区分名の帯（見出し）が入ります。

#### 校正

「校正する」を押すと、次の観点で指摘が出ます。

| 種類 | 例 |
|---|---|
| **表記ルール** | 等 → など、ひとつ → 一つ、様々 → さまざま、子供 → 子ども、〜にて → 〜で |
| **明らかな誤字** | 週知 → 周知、絶対絶命 → 絶体絶命、話しをする → 話をする |
| **同音異義語** | 追求／追及／追究、保証／保障／補償、施行／施工 の使い分け確認 |
| **文法** | ら抜き言葉（見れる → 見られる）、助詞の重複、さ入れ言葉 |
| **記号・数字** | 半角カナ、括弧の対応、機種依存文字（①㈱№）、数字の全角半角 |
| **読みやすさ** | 1文が長すぎる、「が、」の多用、「の」の連続 |
| **ルビ** | 浚渫・暗渠・分賦金などの難読語に読み仮名を提案 |
| **固有名詞** | 山崎 → 山﨑、尾崎 → 尾﨑 など、字形の似た漢字の取り違え |

指摘は3段階で色分けされます。

- **要修正**（赤）— 明確な誤りです
- **確認**（橙）— ハウスルールに合っていない可能性があります
- **参考**（青）— 直すかどうかは編集判断です

「自動で直せる◯件をまとめて修正」で一括修正できます。
**同音異義語とルビの提案は自動修正しません**（文脈によって正解が変わるため）。

> 表記ルールは第203号の Word 原稿と印刷版を突き合わせて、
> 実際に行われている書き換えをそのまま入れてあります。
> 自治体ごとのルールに合わせて `gikai/data/style_rules.json` を編集してください。

#### 字数を枠に合わせる

枠の「1行の字数」と「行数」を入れると、本文の字数・行数が
リアルタイムで表示され、あふれると赤くなります。

字数を減らす方法は2段階あります。

1. **「冗長表現を縮める」** — 意味を変えずに短くします。
   「対応することができる」→「対応できる」、「〜ということである」→「〜という」など。
   **内容は落ちません。**まずこちらを試してください。

2. **「枠に合わせて要約」** — 1で足りないとき、重要度の低い文を落とします。
   各段落の先頭文は優先的に残します。

どちらも、**反映する前に左右の比較画面が出ます。**
機械的な処理なので、必ず内容を確かめてから反映してください。

「見出し候補」を押すと、本文から見出し・リード文の候補を作ります。
そのまま使わず、必ず手直ししてください。

### ④ 写真

写真をドラッグ＆ドロップすると、次を自動で行います。

- **EXIF の回転情報を反映**（スマホで撮った写真が横倒しにならないように）
- **印刷解像度の判定** — 350dpi で刷ったときに何 cm まで使えるかを表示します。
  小さすぎる場合は「元データをもらってください」と警告します
  （メールで縮小された写真は印刷に使えません）
- **枠の縦横比に合わせた切り出し** — 差し込み先を選ぶと、その枠の比率に
  合わせて中央（人物写真を想定して少し上寄り）を切り出します。
  「切り出し確認」で結果を確認できます

説明文（キャプション）と撮影者も、ここで入力しておきます。

#### 原稿の名前で自動割り付け

**写真のファイル名を原稿と同じにしておくと、その記事に結び付けて、
記事が載るページの写真枠へ自動で入れます。** 説明文の枠も、
写真のそばのものを押さえます。

| | 名前の付け方 |
|---|---|
| 原稿 | `森下けい子_原稿.docx` |
| 写真 | `森下けい子_原稿.jpg` |
| 写真が複数 | `森下けい子_原稿1.jpg` `森下けい子_原稿2.jpg`（番号順に並びます） |

`森下けい子_原稿①.jpg` のような丸数字、`森下けい子.jpg` のように
議員名だけでも結び付きます。全角・半角、スペース、`_` や `-` の違いは
無視されるので、神経質にそろえる必要はありません。

「自動で割り付ける」を押すと、**何をどこに入れたかが一覧で出ます。**
判定できなかった写真もそこに出るので、手で選び直してください。

> 写真枠の選び方は「記事が入る枠と同じページにある、まだ使っていない写真枠」です。
> 1ページに複数の枠があるときは、紙面の前のほうから順に埋めます。
> 思ったところに入らなければ、各写真の「差し込み先」で選び直せます。

### ⑤ 紙面に組む

組み方は2つから選べます。

| 組み方 | 内容 | 向いている場面 |
|---|---|---|
| **自動組版**（おすすめ） | 1ページ5段・縦書きは固定したまま、**分量に合わせてページ数と段送りを自動で調節**します | ふだんの号 |
| **前号の様式に差し込む** | 前号 Word の枠に文字と写真を入れ替えます。枠の数と大きさは前号のまま | 特集ページなど、決まった形を再現したいとき |

#### 自動組版

**紙面の決まりごと（判型・段数・縦書き・文字の大きさ・余白）だけを固定し、
中身は Word に組ませます。** 段送りと改ページは Word 自身が行うので、
原稿が増えればページが増え、写真を入れればその分だけ本文が押し出されます。

既定値は第203号の紙面に合わせてあります。

| 項目 | 既定値 |
|---|---|
| 判型 | A4 縦 |
| 段数 | 5段（縦書き） |
| 本文 | ＭＳ 明朝 10.5pt ／ 行送り 1.45倍 |
| 見出し | ＭＳ ゴシック 16pt |
| 余白 | 上15mm・下12mm・左右15mm ／ 段間6mm |

設定を変えると「**1段 13 字 × 33 行（段の高さ 49.2mm）／ 1ページ 約 2145 字**」
のように、その場で字詰めが表示されます。

#### ページ数を合わせる

目標ページ数を入れると、いまの分量が何ページになるか、収めるには
何字詰めればよいかを記事ごとに計算します。

「目標に合わせてまとめて詰める」を押すと、③の要約を全記事に適用します。
**一度で足りなければ自動でくり返し**、それでも入らない場合は
「これ以上は縮まず、約◯ページまでになりました」と正直に伝えます。

> 詰めたあとの本文は、③の各記事で必ず内容をご確認ください。
> 元に戻すときは「取り込んだ原稿に戻す」を押します。

> **ページ数の見積もりについて** — 実際に Word で組んだ結果と
> 突き合わせて計算式を調整してあり、検証した10通りの分量で
> すべて実際のページ数と一致しました。ただし目安であることに変わりはないので、
> 最終確認は Word で開いて行ってください。

#### 前号の様式に差し込む（もう一方の方式）

**前号の Word ファイルをそのまま様式として使えます。**
レイアウト（段組み・縦書き・色・罫線・写真の枠）には一切手を加えず、
**文字と写真の中身だけを差し替えます。**

**様式**については、レイアウトごと扱うため `.docx` が必要です。
`.doc` を読み込んだ場合は自動で変換を試みます（Windows の Word →
LibreOffice の順）。どちらも使えないときは、Word で
「名前を付けて保存 → Word 文書（.docx）」してから読み込んでください。

> 原稿としての `.doc` は、変換なしでそのまま読めます。
> 変換が要るのは様式だけです。

#### 差し込み先の指定

読み込むと、様式の中の文字が入る場所が **枠（スロット）** として一覧に出ます。
「頁」「いまの中身（前号）」「字数」を見ながら、どの記事をどの枠に
入れるかを選びます。枠の字数は、その記事の**字数上限として自動で引き継がれます**。

より確実に指定したい場合は、**差し込みマーカー**が使えます。
Word 側で、差し替えたい場所に次のように書いておくだけです。

```
{{記事1_見出し}}
{{記事1_本文}}
{{写真1_説明}}
```

マーカーがあると、枠の中のその部分だけが差し替わります。
様式を作り直しても番号がずれないので、**毎号使い回す様式にはこちらを推奨します。**

### ⑥ 書き出し

「Word に書き出す」で、`出力/` フォルダに差し込み済みの Word ができます。

- 差し込み先が未設定の記事があれば警告します
- LibreOffice があれば PDF も同時に作れます（Word の「PDF として保存」でも同じです）
- 「紙面プレビュー」は縦書きの下見用です。**最終的な色・罫線は様式が持っている**ので、
  仕上がりの確認は書き出した Word を Word で開いて行ってください

書き出したあとの手順:

1. Word で開く
2. 枠からあふれた文字がないか、見開きで確認する（あふれたら③に戻って詰める）
3. そのまま印刷所に渡す

## 自治体に合わせて調整する

### 固有名詞辞書（画面から編集できます）

右上の「設定」→「この号だけの固有名詞辞書」に、議員名・地名・施設名・
課名を1行ずつ入れてください。ここに登録した語と**1文字だけ違う**表記が
原稿にあると、誤記の可能性として指摘します。

全号で共通に使う語は `gikai/data/local_terms.json` に書いてください。
初期状態では日高村の議員名・地名・課名が入っています。**他の自治体で使う場合は
このファイルを差し替えてください。**

### 表記ルール

`gikai/data/style_rules.json` を編集します。

```json
{ "find": "等", "to": "など", "severity": "warn",
  "note": "本誌は「等」を「など」に開く",
  "context_exclude": ["平等", "等級"] }
```

- `severity` — `error`（要修正）/ `warn`（確認）/ `info`（参考）
- `context_exclude` — 前後にこの語があるときは指摘しない
- `to` に `／` を含めると、自動修正の対象から外れます（人が選ぶべき場合）

### 難読語のルビ

`gikai/data/ruby.json` に「語」と「読み」を追加してください。

### 同音異義語

`gikai/data/confusions.json` の `pairs` に追加してください。

## よくある質問

**Q. 本当にオフラインで動きますか。**
はい。サーバは `127.0.0.1`（このパソコン自身）だけで待ち受けます。
外部のホスト名でアクセスされた場合は拒否します。
画面も外部の CSS やフォントを読み込みません。ネットワークを
切断した状態でも、すべての機能が動きます。

**Q. 要約はどのくらい信用できますか。**
文の重要度を計算して選ぶ方式（抽出型）で、**文章を作り直すことはしません**。
残った文はすべて原稿にあった文そのものなので、事実が変わることはありませんが、
**文脈がつながらなくなることはあります。**必ず目で確認してください。
言語モデルは使っていません（オフラインで動かすため）。

**Q. 校正で見落としはありますか。**
あります。辞書に無い誤字や、文脈依存の誤りは検出できません。
**人の校正を置き換えるものではなく、機械的に見つかるものを先に潰して、
人の目を内容の確認に回すための道具**と考えてください。

**Q. Word のレイアウトが崩れませんか。**
差し込みは、段落の書式（フォント・サイズ・縦書き・字下げ）を保ったまま
文字だけを入れ替えます。枠・段組み・図の位置には触れません。
ただし **文字数が増えれば枠からあふれます。**③の字数表示で
枠に収まる長さにしてから書き出してください。

**Q. 複数人で同時に編集できますか。**
できません。1つの号は1人ずつ編集してください。
フォルダをコピーして渡す形で分担することはできます。

**Q. 前の状態に戻せますか。**
記事ごとに「取り込んだ原稿に戻す」で、取り込んだ直後の状態に戻せます。
原稿の原本は `manuscripts/` に、写真の原本は `photos/` にそのまま残ります。
書き出した Word は毎回 `出力/` に作られるので、上書き前のものを残したい場合は
書き出し時にファイル名を変えてください。
